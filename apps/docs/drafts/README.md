# Unpublished docs

Pages written ahead of a launch. Nothing here is built or served: only
`content/` and `public/` are.

- `setup-teardown-scripts.mdx`: the `.superset/config.toml` version of
  `content/docs/setup-teardown-scripts.mdx`, held back while the format is
  behind the `workspace-config-toml` flag. At launch, replace the published page
  with it and move `images/` to `public/images/`.
