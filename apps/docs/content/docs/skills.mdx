Skills teach the coding agents you already use how to drive Paradev: orchestrate parallel agents, create automations, diagnose problems, and more.

<YouTubeVideo id="8g-l5kYEGBc" title="Paradev CLI + Skills Demo" thumbnail="/images/cli-skills-demo.jpg" />

## Installation

**Using the Paradev desktop app?** Skills are already installed. The app provisions them at launch and keeps them updated.

Otherwise, install them directly:

```bash
npx skills add paradevai/skills
```

Or, in Claude Code, via the plugin marketplace:

```text
/plugin marketplace add paradevai/paradev
```

## What You Get

| Skill | What it does |
|:------|:-------------|
| `paradev:setup` | Makes a repo Paradev-ready: authors `.paradev/config.toml` (or updates an existing `.superset/` config) and project lifecycle scripts, then verifies with a real workspace |
| `paradev:orchestrate` | Turns the agent you're talking to into a coordinator of parallel agents; see [Agent Orchestration](/orchestration) |
| `paradev:automate` | Turns a recurring chore into an [automation](/automations) that runs on a schedule or an event, and reviews its first run with you |
| `paradev:page` | Builds and publishes shareable [Pages](/pages), then updates them in response to pinned team comments |
| `paradev:browser` | Drives a workspace's [in-app browser](/browser) panes: open, navigate, screenshot, eval, read console, and raw CDP for click/type automation, and routes to [Browser Use 3.0](/browser#browser-use-30) for browsers the panes can't reach |
| `paradev:computer` | Drives [native desktop apps](/computer) through an accessibility-first driver (Cua Driver by default): inspect windows, click, type, use menus, and verify results with background interaction when the platform supports it |
| `paradev:panes` | Arranges a workspace's tabs and split panes in the desktop app: split, open tabs, resize, swap, move, focus, and close, with commands running in the new panes; see the [`panes` CLI reference](/cli/cli-reference#panes) |
| `paradev:standup` | Sweeps your workspaces, tasks, and agent terminals into a digest: what needs you, what's in flight, what's blocked |
| `paradev:doctor` | Diagnoses Paradev problems (expired auth, offline hosts, stale versions) and fixes them one step at a time |
| `paradev:feedback` | Files a bug report or feature request: privately to the Paradev team (from your account, so we can reply) or as a public GitHub issue |
| `paradev:10x` | Audits how you use Paradev and teaches the advanced features you're not using yet |
| `paradev:contribute` | Sets up a Paradev open-source contribution end to end, following the repo's contribution rules |

## Using Skills

You usually don't invoke them; agents pick the right skill from context:

- "report this bug to the Paradev team" → `paradev:feedback`
- "what did my agents do overnight?" → `paradev:standup`
- "run these three refactors in parallel" → `paradev:orchestrate`
- "open localhost:3000 and click through the signup flow" → `paradev:browser`
- "open the desktop app and change its settings" → `paradev:computer`
- "split this and run the tests on the right" → `paradev:panes`

To invoke one explicitly: `/paradev:feedback` in Claude Code, or `/paradev/feedback` in the in-app chat. Other agents that read skills (Codex, Kimi, Vibe, Grok) see the same skills with a `paradev-` prefix.

The old names still work: `superset:feedback` and `superset-feedback` stay as aliases, so saved prompts and automations keep running. A plugin installed from the Claude Code marketplace above is still named `superset`, so there its skills answer to `superset:` only.

## How They're Delivered

At launch, the desktop app writes managed copies into the standard discovery locations: `~/.claude/skills/paradev/` (loaded by Claude Code as a plugin, hence the `paradev:` namespace) with its old-name twin `~/.claude/skills/superset/`, `~/.agents/skills/`, and `~/.agents/commands/`.

- **Your files are never touched.** Managed files carry a marker; a skill or command you authored at the same path is left alone.
- **Updates are automatic.** Managed skills refresh on every app launch, and ones that no longer ship are cleaned up.
