---
title: Chat interface
description: Run a coding agent as a chat instead of a terminal, and which agents support it
---

The chat interface shows an agent session as a chat instead of a terminal. The agent's messages, tool calls, and file edits appear as a transcript, and you approve or decline actions with a click.

The agent is the CLI you already installed, which Paradev runs over the [Agent Client Protocol](https://agentclientprotocol.com), so a chat uses the same login, settings, and MCP servers as the CLI in a terminal. A session can move between chat and terminal without starting over.

## Open a Chat

- **New workspace:** pick a supported agent when you create a workspace, and its session opens as a chat.
- **Existing agent terminal:** use the **CLI** / **Chat** toggle in the agent pane's header. Switching resumes the same session, so the agent keeps its context. Switch back to **CLI** at any time.

The toggle appears for running sessions of supported agents.

## Supported Agents

| Agent | Chat interface | Minimum CLI version | Upgrade |
|:------|:-------:|:--------------------|:--------|
| Claude Code | ✅ | 2.1.226 | `npm i -g @anthropic-ai/claude-code@latest` |
| Codex | ✅ | 0.160.0 | `npm i -g @openai/codex@latest` |
| OpenCode | ✅ | 1.15.5 | `npm i -g opencode-ai@latest` |
| Pi | ✅ | Any | None |
| Other agents | No | None | None |

If your CLI is older than the minimum, Paradev tells you and shows the upgrade command. Agents without chat support still run in a Paradev terminal.
