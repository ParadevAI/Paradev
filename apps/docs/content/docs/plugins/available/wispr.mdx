Search and read your Wispr Flow meeting notes, transcripts, scratchpad notes, and calendar events.

## MCP Server

Tools come from Wispr Flow's own MCP server at `https://api.wisprflow.ai/connect/mcp`. Paradev proxies each call and adds your credentials. The server is read-only. Wispr Flow lists Notetaker with Cloud Sync turned on as a requirement for meeting notes and transcripts. On Enterprise accounts, an admin must enable the Wispr Flow MCP connector.

## Authentication

| Method | Details |
|:-------|:--------|
| OAuth 2.0 | You sign in to Wispr Flow in your browser. Paradev registers itself with Wispr Flow when you connect, so there is no app to set up first. |

Connect from the plugin's page in **Plugins**. Paradev keeps the credentials. The agent and your machine never see them.
