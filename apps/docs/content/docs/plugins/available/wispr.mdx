Search and read your Wispr Flow meeting notes, transcripts, scratchpad notes, and calendar events.

## Skills

| Skill | What it does |
|:------|:-------------|
| `find-in-wispr` | Answers "what did we say or decide" from your meetings and preps you for the next one, with a citation for each claim |

Skills are named `wispr-<skill>`. In Claude Code they appear as `superset:wispr-<skill>`.

## MCP Server

Tools come from Wispr Flow's own MCP server at `https://api.wisprflow.ai/connect/mcp`. Paradev proxies each call and adds your credentials. The server is read-only. Meeting notes and transcripts need Notetaker with Cloud Sync turned on. On Enterprise accounts, an admin must enable the Wispr Flow MCP connector.

## Authentication

| Method | Details |
|:-------|:--------|
| OAuth 2.0 | You sign in to Wispr Flow in your browser. Paradev registers itself with Wispr Flow when you connect, so there is no app to set up first. |

Connect from the plugin's page in **Plugins**. Paradev keeps the credentials. The agent and your machine never see them.
