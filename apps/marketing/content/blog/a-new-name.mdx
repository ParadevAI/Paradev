Paradev, formerly Superset, is a desktop app for running many coding agents in parallel, each in its own Git worktree. Superset became Paradev on October 26, 2026. Only the name, logo, website, and email domain changed. The product, your account, and your workspaces stay the same. Read the [announcement](/blog/superset-is-now-paradev) for the full story.

## Why

There are many companies and projects with the same name, such as [Apache Superset](https://superset.apache.org/). We've been looking for something that's truly ours to build an enduring company on. We found it in Paradev.

## What changes

Only the name changed, on October 26, 2026. Our logo, website and email domain changed with it: the website is now [paradev.com](https://paradev.com).

## What doesn't change: your product and account

Nothing else will change: same product, team, and mission.

- The product, features and team.
- Your account, workspaces, settings, agents and billing.
- Your links and integrations. Every superset.sh page redirects to the same page on paradev.com, and existing docs links keep working.

The desktop app picks up the new name on its own, and the `superset` command in your terminal keeps working.

## What Paradev does

Paradev is a desktop app for macOS, with an experimental Linux build, for running coding agents side by side. Each task gets its own workspace with a Git worktree, branch, terminals, and ports.

- **Several tasks at once.** Start an agent in each workspace and keep working. The Workspaces board shows which agents are working, need your input, or have a change ready for review.
- **The agents and subscriptions you already have.** Run Claude Code, Codex, OpenCode, Cursor's agent, Copilot CLI, and other CLI agents. They use your own subscriptions and API keys, and Paradev does not bill model usage.
- **Review before you merge.** Read each workspace's diff, send follow-ups, open a pull request, and check CI from the same window. You can send line comments from a pull request back to the agent.
- **Away from your desk.** The iPhone and iPad app lets you answer agents and review diffs on your connected machines. It needs Paradev Pro.
