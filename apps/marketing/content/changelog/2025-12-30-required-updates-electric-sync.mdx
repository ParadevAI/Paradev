## Electric SQL Sync <PRBadge url="https://github.com/superset-sh/superset/pull/511" />

- A new task UI lets you create and edit tasks and track their status
- You can switch between organizations and belong to more than one
- Task data syncs local-first through Electric SQL
- Task updates sync in both directions, and your changes go back to Linear through its API

## Linear Integration <PRBadge url="https://github.com/superset-sh/superset/pull/503" />

- Connect Linear to Superset with OAuth
- A new integrations page lets you connect and configure third-party services
- Tasks sync between Linear and the app, with priority and team settings
- Changes in Linear arrive in real time through a webhook

## Required Updates <PRBadge url="https://github.com/superset-sh/superset/pull/552" />

- The desktop app now requires at least the version that our server sets
- A new "Update Required" screen helps blocked users check for, download, or install an update
- The UI knows the current app version, so version checks are accurate
- If the API is unreachable, the app stays open and checks again when the network returns

## Confirm on Quit <PRBadge url="https://github.com/superset-sh/superset/pull/524" />

- A new "Behavior" section in Settings has a "Confirm before quitting" toggle, on by default
- When the toggle is on, the app asks before it quits, and the setting persists across restarts
- Updates, installs and quits that the app starts itself can skip the dialog, so updates are not blocked
