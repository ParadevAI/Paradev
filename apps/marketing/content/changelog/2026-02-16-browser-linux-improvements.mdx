## Chat - Still in preview <PRBadge url="https://github.com/superset-sh/superset/pull/1413" />

Chat got a large update this week. You can now review and approve each tool call as a response streams. A new model picker lets you choose between providers and models. Agent and tool calls render as expandable blocks with a display for each tool, and a new web search tool lets Claude fetch and cite live content.

We also fixed MCP connectivity. A direct SDK transport replaces the `mcp-handler` library <PRBadge url="https://github.com/superset-sh/superset/pull/1518" />, OAuth connections work through the reverse proxy <PRBadge url="https://github.com/superset-sh/superset/pull/1512" />, and SDK version conflicts no longer cause session failures <PRBadge url="https://github.com/superset-sh/superset/pull/1515" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1516" />.

![Chat with tool approval](/changelog/chat.png)

## In-App Browser <PRBadge url="https://github.com/superset-sh/superset/pull/1519" />

Browse documentation, preview dev servers, and test web apps without leaving Paradev. The new embedded browser has Chrome-like URL autocomplete with browsing history, favicon capture, and DevTools support.

- Open a detected port in a browser pane: click the external link icon, and it opens there instead of in your system browser
- URL bar with saved history and keyboard navigation
- Clear browsing data from the overflow menu
- Open a browser tab with ⌘⇧B

![In-app browser](/changelog/browser.png)

## Desktop Automation Tools <PRBadge url="https://github.com/superset-sh/superset/pull/1481" />

New MCP automation tools let Claude Code control the Paradev UI. Claude can now take screenshots, click UI elements, type into fields, and inspect the DOM, so you can run automated tests and debugging in plain language.

## Improvements

- **Linux desktop support** - Paradev Desktop is now available on Linux, with auto-updates through AppImage builds <PRBadge url="https://github.com/superset-sh/superset/pull/1477" />
- **Terminal context menu** - Right-click to copy selected text or paste from clipboard <PRBadge url="https://github.com/superset-sh/superset/pull/1509" />
- **Workspace visual identity** - Each workspace gets its own colored dock icon border, so you can tell workspaces apart in development <PRBadge url="https://github.com/superset-sh/superset/pull/1478" />
- **Open tasks in workspace** - The new "Open in workspace" button in task detail creates a workspace and launches Claude with the full task context <PRBadge url="https://github.com/superset-sh/superset/pull/1473" />
- **Ahead/behind indicators** - See commit sync status on workspace items in the sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/1496" />
- **Preset hotkey tooltips** - Hover a preset bar item to see its keyboard shortcut <PRBadge url="https://github.com/superset-sh/superset/pull/1469" />
- **Branch name sanitization** - Git branch names now keep valid characters such as underscores, dots, and at signs <PRBadge url="https://github.com/superset-sh/superset/pull/1470" />
- **Port allocation improvements** - The generated ports.json has readable labels, and port allocation moves to a shared file for CLI workflows <PRBadge url="https://github.com/superset-sh/superset/pull/1479" />
