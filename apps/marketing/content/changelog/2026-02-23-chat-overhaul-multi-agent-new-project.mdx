## Copilot, Cursor Agent, and Gemini Support <PRBadge url="https://github.com/superset-sh/superset/pull/1630" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1625" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1620" />

Paradev now supports Copilot, Cursor Agent, and Gemini CLI alongside Claude, Codex, and OpenCode. Copilot and Gemini get built-in presets and hook support, and Cursor Agent is an agent option in the multi-agent workflow.

- Ready-to-use terminal presets for Copilot and Gemini CLI
- Cursor Agent in agent selection and commands
- Correct defaults per agent (`--allow-all` for Copilot, `-y` for Gemini)
- Paradev notification hooks show in the UI when an agent finishes a task

## Configurable Worktree Location <PRBadge url="https://github.com/superset-sh/superset/pull/1626" />

Set a custom base directory for new worktrees in **Settings → Behavior**. You can also override it for one project in Project settings. The project setting wins, and a reset option returns to the global default.

![Custom worktree location settings](/changelog/worktree-location.png)

## New Project Page <PRBadge url="https://github.com/superset-sh/superset/pull/1623" />

Project creation now has its own full page instead of a dialog. Open it from the welcome screen or the sidebar footer, then pick one of two options: create an empty Git repo or clone from a URL. A template starter tab is visible and marked "coming soon." The directory picker defaults to `~/.superset/projects` and has a native browse button.

## Chat UI Overhaul (Early access only) <PRBadge url="https://github.com/superset-sh/superset/pull/1693" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1697" />

The chat interface has a new look. Streaming messages now type out as they arrive, tool output panels collapse to reduce noise, and loading and thinking states share one compact shimmer. The input composer has pill-shaped toolbar buttons, a circular submit button, and a cleaner layout with a hint row for `@` mentions and `/commands` shortcuts.

- Progressive typing animation for streaming messages
- Collapsible tool output panels with inline status icons
- Pill-style controls for model picker, permission mode, and thinking toggle
- Clearer permission mode labels: Auto, Semi-auto, and Manual

## More Improvements

- **Open links in app** - A new toggle in **Settings → Behavior** opens chat links and terminal URLs in the built-in browser pane instead of your system browser <PRBadge url="https://github.com/superset-sh/superset/pull/1690" />
- **Drag file paths into chat** - Drag a file from the file tree or changes panel into the chat input to insert its path as text <PRBadge url="https://github.com/superset-sh/superset/pull/1656" />
- **⌘F in markdown viewer** - Full-text search now works in rendered markdown documents <PRBadge url="https://github.com/superset-sh/superset/pull/1661" />
- **Task search persisted in URL** - The task search query survives navigation and page refreshes <PRBadge url="https://github.com/superset-sh/superset/pull/1680" />
- **Chat scrollback rail** - A scroll position indicator appears when you browse older messages in chat <PRBadge url="https://github.com/superset-sh/superset/pull/1648" />
- **Copy commit hash** - Right-click a commit header in the diff view to copy its hash <PRBadge url="https://github.com/superset-sh/superset/pull/1686" />
- **Tray quit confirmation** - Quitting with active daemon sessions now asks whether to keep or kill them <PRBadge url="https://github.com/superset-sh/superset/pull/1651" />
- **Clear workspace status** - The workspace context menu now has "Clear status" <PRBadge url="https://github.com/superset-sh/superset/pull/1633" />
- **Mouse side buttons** - Back and forward navigation now works with mouse side buttons <PRBadge url="https://github.com/superset-sh/superset/pull/1624" />
- **Slack image attachments** - The Slack agent can now send image attachments <PRBadge url="https://github.com/superset-sh/superset/pull/1671" />
