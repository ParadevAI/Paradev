## Improved Chat View: Now Generally Available <PRBadge url="https://github.com/superset-sh/superset/pull/1876" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1973" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1983" />

The redesigned chat interface is out of early access and now generally available to all users. It has refreshed tool call visuals with collapsible panels, improved diff rendering, and cleaner file views. Paradev's own MCP tools (tasks, workspaces, and agent sessions) now render as interactive cards in the chat. Paradev Chat is also an agent option with its own launch config and icon.

- Refreshed tool call visuals with collapsible output panels and inline status icons
- Rich UI cards for Paradev MCP tool calls (tasks, workspaces, agent sessions)
- Paradev Chat available as a built-in agent alongside Claude, Codex, and others
- Agent questions render as markdown, and your answer shows right away

## Open Worktree with Prompt <PRBadge url="https://github.com/superset-sh/superset/pull/1882" /> <PRBadge url="https://github.com/superset-sh/superset/pull/1912" />

The new workspace modal can now send a prompt to an agent in the new workspace. When you create a worktree, describe what you want built, and the agent starts as soon as the workspace is ready. The modal also has a project selector, an import flow to clone repos, and branch names generated from your prompt.

![Open worktree with prompt](/changelog/ws-prompt.png)

- Write a task prompt when creating a new workspace
- Agent starts working immediately in the new worktree
- Auto-generated branch names from prompt content
- Keyboard shortcut hint (⌘/Ctrl+Enter) on the create button

## Start Project from Template <PRBadge url="https://github.com/superset-sh/superset/pull/1913" />

New users now see a multi-step setup wizard when they open a project for the first time. It detects the environment files and package managers in the repo, guides you through setup scripts, and links to the docs. The new project flow also has a Next.js Chatbot template, so you can start a project from a pre-built starter.

![Start project from template](/changelog/template.png)

- Multi-step wizard with setup script detection
- Auto-detection of env files and package managers
- Next.js Chatbot project template via vercel/chatbot
- Docs links on each setup step

- **Open changes pane from file edits** - When an agent edits a file in chat, you can jump to the changes pane to review the diff <PRBadge url="https://github.com/superset-sh/superset/pull/1868" />
