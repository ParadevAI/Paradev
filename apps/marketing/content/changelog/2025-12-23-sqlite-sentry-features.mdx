## SQLite Local Database <PRBadge url="https://github.com/superset-sh/superset/pull/477" />

- The desktop app now keeps its data in a local SQLite database, and your data moves over from the old JSON store automatically
- The new database has a typed schema and migrations
- Every database operation now uses SQLite, not the old `db.json` file
- Every ID field is a UUID by default, to prepare for a local-first architecture

## Sentry Error Tracking <PRBadge url="https://github.com/superset-sh/superset/pull/484" />

- The desktop app now has error tracking and monitoring, for better stability reports
- Sentry covers both the main and renderer processes
- The app captures backend errors automatically, with their path, type and code
- New developer tools test that error reports work

## Features and FAQ Sections <PRBadge url="https://github.com/superset-sh/superset/pull/472" />

- A new Features section alternates text and images to show Parallel Agents, Universal CLI Support, and Git Worktree Integration
- A new FAQ section has two columns and smooth accordion animations
- The accordion has a plus icon that turns to an X when open
- Five interactive demos: file and diff, IDE file tree, terminal, compatibility, and parallel execution
