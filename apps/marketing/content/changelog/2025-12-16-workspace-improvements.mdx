## VS Code-Style Resizable Sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/457" />

- The sidebar is a new resizable panel, and its width is no longer a percentage of the window
- The width is in pixels (250px by default, from 200px to 500px), so the size stays consistent
- Drag the sidebar edge to resize it, as in VS Code
- The drag handle is 12px wide and invisible, which makes it easy to grab, and the visible line stays thin

## Multiple Terminal Tabs <PRBadge url="https://github.com/superset-sh/superset/pull/452" />

The **New Terminal** button creates a new tab again. A regression made it only switch to an existing tab. Each workspace can have more than one terminal tab, so you can run work in parallel.

## Port Visibility <PRBadge url="https://github.com/superset-sh/superset/pull/462" />

![Ports panel](/changelog/ports.png)

- Superset detects listening ports from terminal output and checks that each port is active before it shows it
- A new Ports panel in the sidebar groups ports by workspace, with quick actions (open in browser, jump to pane)
- The list updates in real time as ports appear and disappear
- When a terminal pane closes, its ports leave the list

## Multi-line URL Links <PRBadge url="https://github.com/superset-sh/superset/pull/467" />

- A URL that wraps across terminal lines now works as one link
- Other link types can use the same logic for wrapped links
- A custom link provider replaces the old web links add-on, so wrapped links behave the same way everywhere
