## Pull Requests Open as a Pane <PRBadge url="https://github.com/superset-sh/superset/pull/7244" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7503" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7500" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7400" />

A pull request now opens inside the workspace. Every PR link in the app opens a pane beside your diff with the title, checks, description, and merge menu. That covers the Open PR button in the Changes pane, the PR icon on a sidebar row, and the "PR created" toast.

- Review and conversation comments show below the description. Reply, resolve, or follow a link that opens the file at that line in a diff pane
- A copy button in the pane header copies the GitHub URL, and a header link opens the full Pull requests screen
- The Pull requests screen now filters by more than one author at once, so a small team can follow its own PRs together

![Review comments below the description in the pull request pane, with Open in diff on each thread](/changelog/2026-09-13-pr-comments.png)

## Subagents Under Their Agent <PRBadge url="https://github.com/superset-sh/superset/pull/7231" />

When Claude Code or Codex starts a subagent, the subagent now shows under its parent in the workspace row's agents chip, with its type as a label. Click a subagent row to open a pane that follows its transcript live and shows Finished at the end. Hover the agents chip on any workspace row to see them.

![The agents popover on a workspace row, with four subagents nested under their Claude session](/changelog/2026-09-13-subagents.png)

## Muse Code and Devin Agents, OpenCode History and Quotas <PRBadge url="https://github.com/superset-sh/superset/pull/7458" />

Meta's Muse Code and Devin's CLI are now in the built-in agent catalog, with session resume and token history. OpenCode sessions show up in Usage again, and OpenCode's Anthropic and OpenAI logins have their own quota cards. Add either agent from **Settings → Agent commands → Add agent**.

![The Add agent menu with Muse Code and Devin at the bottom](/changelog/2026-09-13-agent-picker.png)

## Pages on Your Phone, and Cleaner Comments <PRBadge url="https://github.com/superset-sh/superset/pull/7367" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7312" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7470" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7359" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7473" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7471" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7339" />

When an agent publishes a page, you can now read it and leave feedback in the iOS app. Pick an element to comment on it, as on the desktop.

- The comment button only turns on comment mode; a floating All comments button opens the thread list and keeps it open
- Enter sends a comment, resolved pins disappear, and a Delete this request turns its pin red
- Published pages use Paradev's typography and colors, and a page opened in a browser has an Open in Paradev button
- **Settings → Links** has a Pages row, so page links can open in Paradev while other URLs go to your browser
- The Pages screen offers Create with AI, which opens an agent workspace already set up to publish a page

Docs: [docs.superset.sh/docs/pages](https://docs.superset.sh/docs/pages).
