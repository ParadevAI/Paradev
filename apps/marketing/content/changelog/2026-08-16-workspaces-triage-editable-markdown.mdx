## A Workspaces Page Built for Triage <PRBadge url="https://github.com/superset-sh/superset/pull/6506" />

The Workspaces page now groups every workspace by what needs you: Needs attention, Working, Needs review, Idle, Merged. Each row shows live agent status, diff size, PR checks progress, and last activity. You can check all your agents without opening a workspace.

- Sort by last activity, created, diff size, or name; sections collapse and stay collapsed
- A new **All devices** option in the device filter shows workspaces from every host in one view <PRBadge url="https://github.com/superset-sh/superset/pull/6478" />

Open **Workspaces** in the sidebar and pick the list view.

![The Workspaces page grouping rows into Working, Needs review, and Idle sections with diff stats and PR checks](/changelog/2026-08-16-workspaces-triage.png)

The board view shows the same groups as columns, so the two views always agree. Switch between them with the toggle next to the sort control.

![The Workspaces board view with Working, Needs attention, Needs review, and Merged columns of workspace cards](/changelog/2026-08-16-workspaces-board.png)

## Edit Markdown in the Rendered Preview <PRBadge url="https://github.com/superset-sh/superset/pull/6406" />

You can now edit markdown files in the Preview view: type anywhere, click checkboxes, format with the selection menu, and save with ⌘S. A save rewrites only the blocks you changed. Bullet styles, hand-wrapped lines, front matter, and raw HTML stay byte-identical, so your git diffs stay clean. The source view is still one toggle away.

![Editing a markdown checklist in the rendered preview with the formatting menu open over selected text](/changelog/2026-08-16-markdown-preview.png)

## Manage App Settings from the CLI <PRBadge url="https://github.com/superset-sh/superset/pull/6402" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6418" />

You can now script desktop settings and themes: 35 settings across behavior, git, notifications, and typography, with no cloud login. Changes apply to a running app at once, themes included.

```bash
superset settings list
superset settings set terminalFontSize 16
superset settings theme set dark
```

Typical uses: an agent adjusts your setup from a Paradev terminal, dotfiles configure the app on a new machine, or you change a setting without leaving your shell.

## Sidebar Groups Go Anywhere <PRBadge url="https://github.com/superset-sh/superset/pull/6514" />

Groups in the sidebar no longer stay at the bottom of a project. Drag them above, between, or below ungrouped workspaces, and the order stays. The Pinned and Sessions sections now collapse too, like Projects <PRBadge url="https://github.com/superset-sh/superset/pull/6407" />.

## Improvements

- **Host unreachable screen** - when a workspace's host stops answering, one screen shows live reconnect status and a retry button instead of failing panes; the panes stay open underneath, so you keep terminal scrollback and unsaved edits <PRBadge url="https://github.com/superset-sh/superset/pull/6476" />
- **Folder links open in Finder** - set what terminal folder links do under **Settings → Links**, with ⇧ Click bound to Open in Finder; paths outside the worktree now open in Finder too <PRBadge url="https://github.com/superset-sh/superset/pull/6504" />
- **Remote Workspaces settings** - the Security tab is now called Remote Workspaces, and the relay toggle is also on your local host's page under **Settings → Hosts** <PRBadge url="https://github.com/superset-sh/superset/pull/6481" />
- **Faster sidebar on big repos** - file tracking skips gitignored build directories, which cuts background git work, and files in ignored folders now reload live in open editors <PRBadge url="https://github.com/superset-sh/superset/pull/6379" />
- **Sign in with Apple** - on the iOS app <PRBadge url="https://github.com/superset-sh/superset/pull/6392" />
- **Mobile composer and sessions** - the terminal composer has dictation and attachments, you can reorder terminal sessions from the sessions sheet, and home has a group for each project, with the active scope named on screen <PRBadge url="https://github.com/superset-sh/superset/pull/6482" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6488" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6512" />
- **Mobile requires a paid plan** - the iOS app is now Pro-only; free accounts keep home and settings <PRBadge url="https://github.com/superset-sh/superset/pull/6414" />
- **Delete your account with a grace period** - request deletion from any client and reactivate within 30 days <PRBadge url="https://github.com/superset-sh/superset/pull/6395" />
- **Connect any agent to Paradev** - one-line MCP installs for Claude Code, Codex, Gemini CLI, and more at [superset.sh/mcp-install](https://superset.sh/mcp-install) <PRBadge url="https://github.com/superset-sh/superset/pull/6493" />
