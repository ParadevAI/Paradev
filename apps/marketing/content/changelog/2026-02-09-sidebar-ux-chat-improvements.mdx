## New Diff View, Powered by diffs.com <PRBadge url="https://github.com/superset-sh/superset/pull/1308" />

The Changes view now runs on [Pierre Computer's diffs.com](https://diffs.com) engine, with a better interface and faster rendering. Large changesets that lagged before now render instantly.

The new viewer has an edit mode toggle. Switch between read-only review and live editing, and press Ctrl+S to save changes from the diff.

- **Workspace-scoped base branch** - each workspace now has its own base branch, so diffs always compare against the right branch <PRBadge url="https://github.com/superset-sh/superset/pull/1329" />
- **Preserved file explorer state** - expanded folders, scroll position, and selection stay when you switch between the Changes and Files tabs <PRBadge url="https://github.com/superset-sh/superset/pull/1297" />
- **Compact tab buttons** - the Changes and Files tabs collapse to icons with tooltips when the sidebar is narrow <PRBadge url="https://github.com/superset-sh/superset/pull/1334" />

## Early Preview of Chat GUI <PRBadge url="https://github.com/superset-sh/superset/pull/1309" />

Paradev now has a native AI chat interface that works with your existing Claude Code sessions. Pick up where you left off without switching windows.

- **Existing session support** - scan and restore earlier Claude Code sessions, so you keep your context
- **Slash commands** - type `/` to browse commands with fuzzy search and keyboard navigation
- **File mentions** - tag files with `@` and fuzzy search to add them as context <PRBadge url="https://github.com/superset-sh/superset/pull/1307" />
- **Rich tool rendering** - tool calls show a dedicated UI for bash output, web searches, file diffs, and user questions
- **Session persistence** - chat sessions save locally and restore automatically after an app restart <PRBadge url="https://github.com/superset-sh/superset/pull/1287" />

This is an early preview. General availability is coming next week. We'd love your feedback in the meantime.

![Chat GUI with slash commands and tool rendering](/changelog/chat-gui.png)

## Preset Settings <PRBadge url="https://github.com/superset-sh/superset/pull/1320" />

Terminal presets now have separate auto-apply controls for workspace creation and new tabs. You can run setup commands on each new workspace without running them every time you open a tab.

- **Apply preset on workspace creation** - controls the setup commands that run when you create a workspace
- **Apply preset on new tab** - controls whether presets run when you open a new tab, pane, or split
- A preset you launch from a hotkey or the menu always runs, whatever these settings are

## Improvements

- **Improved new tab buttons** - New Terminal and New Chat sit in one outlined button bar and show their shortcuts (⌘T, ⌘⇧T) <PRBadge url="https://github.com/superset-sh/superset/pull/1321" />
- **Setup script card** - a sidebar card replaces the toast for a missing setup script and links to the configuration <PRBadge url="https://github.com/superset-sh/superset/pull/1270" />
- **Push auto-setup** - the first `git push` from a worktree creates the remote branch and sets upstream tracking <PRBadge url="https://github.com/superset-sh/superset/pull/1267" />
- **Project image toggle** - hide or show project GitHub avatars in the sidebar, with colored initial letters as the fallback <PRBadge url="https://github.com/superset-sh/superset/pull/1276" />
- **Teardown logs modal** - a failed teardown script shows its logs in a modal, not in the error toast <PRBadge url="https://github.com/superset-sh/superset/pull/1277" />
