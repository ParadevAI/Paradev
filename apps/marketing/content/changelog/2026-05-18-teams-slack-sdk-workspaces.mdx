You can now use Paradev from more places than the desktop app: a fuller CLI and a TypeScript SDK, a Slack agent that creates workspaces on its own, and a mobile app in internal review.

## Automations

**Automations are cron jobs for agent sessions.** Pick a project, write a prompt, set a schedule, and Paradev starts an agent run in a fresh workspace each time it fires. The output is a live workspace that you can open, review, and continue.

Typical uses:

- **Nightly standups**: summarize PRs, issues, and activity from the last 24 hours
- **Release notes**: draft from merged commits each week
- **Security & dependency sweeps**: scan for vulnerable packages or deprecated APIs every morning
- **Long-running refactors**: "bump TypeScript to 5.7 in the next un-migrated package" every day

New in this batch:

- **Prompt version history** <PRBadge url="https://github.com/superset-sh/superset/pull/3996" />: Paradev saves every edit to an automation's prompt. Browse earlier versions and restore any of them to undo an accidental change.
- **Redesigned automations tab** <PRBadge url="https://github.com/superset-sh/superset/pull/4225" />: a new layout that makes a queue of runs easier to scan.
- **Mine vs. Team filter** <PRBadge url="https://github.com/superset-sh/superset/pull/4403" />: automations now belong to a team. Switch the runs view between **Mine** and **Team** to see only your runs or all your team's runs.

### Drive them from the CLI

You can now script everything the UI does. New in this batch: `prompt get` / `prompt set` <PRBadge url="https://github.com/superset-sh/superset/pull/3966" /> and the `--name` filter on list <PRBadge url="https://github.com/superset-sh/superset/pull/3959" />.

```bash
# create a recurring run from a prompt file
superset automations create \
  --name "Nightly audit" \
  --rrule "FREQ=DAILY;BYHOUR=3;BYMINUTE=0" \
  --project <projectId> \
  --agent claude \
  --prompt-file prompt.md

# manage the queue
superset automations list --name "Nightly"
superset automations pause <id>
superset automations resume <id>

# iterate on the prompt (backed by the new version history)
superset automations prompt get <id> > prompt.md
$EDITOR prompt.md
superset automations prompt set <id> --file prompt.md

# fire one off-schedule (also works from the SDK / Slack bot / MCP)
superset automations run <id>
```

`superset automations run` is also available in the **TypeScript SDK** and **MCP**, so you can start runs from a CI job, an internal admin panel, or a Slack slash command. See the [Automations docs](https://docs.superset.sh/docs/automations) for the full list.

## Paradev CLI

The `superset` CLI now has project and workspace commands and a login that works across devices.

**New commands:**

- `superset projects create` <PRBadge url="https://github.com/superset-sh/superset/pull/4355" />: create a new Paradev project from your shell.
- `superset projects setup` <PRBadge url="https://github.com/superset-sh/superset/pull/4356" />: link an existing local repo to a Paradev project.
- `superset workspaces open` <PRBadge url="https://github.com/superset-sh/superset/pull/4258" />: open a workspace from the terminal.
- `superset auth login` <PRBadge url="https://github.com/superset-sh/superset/pull/3965" />: now uses OAuth device code + PKCE, so it works on headless servers and across devices.

**Setting it up:**

```bash
# install
curl -fsSL https://superset.sh/cli/install.sh | sh
# or: brew install superset-sh/tap/superset
# or: it's already bundled with the desktop app at ~/.superset/bin/superset

# sign in (opens a browser, or prints a code for a second device)
superset auth login

# scaffold a project and open a workspace
superset projects create
superset workspaces open
```

The **TypeScript SDK** <PRBadge url="https://github.com/superset-sh/superset/pull/3937" /> (`@superset_sh/sdk`) mirrors the CLI 1:1. Anything you can do from your shell, you can do from a script, a CI job, or an internal tool.

```bash
npm install @superset_sh/sdk
```

```ts
import Superset from '@superset_sh/sdk';
const client = new Superset(); // reads SUPERSET_API_KEY / SUPERSET_ORGANIZATION_ID
await client.automations.run('<automation-id>');
```

`superset start` and `superset update` now work on Linux <PRBadge url="https://github.com/superset-sh/superset/pull/4635" />.

## Slack bot

![Paradev Slack bot spinning up a workspace and reporting back in-thread](/changelog/slack.png)

`@superset` in Slack is now an agent that does more than file tasks. Mention it in a channel or DM it, and it can:

- **Create, update, search, and triage tasks** from the conversation it is in. It reads assignees, statuses, and priorities from your team's Linear/Paradev setup.
- **Spin up a cloud workspace and launch a coding agent** to do the work. For a code-change request (e.g. "@superset bump our Sentry SDK to v9 across all apps"), it now creates a workspace and an agent by default and does not only file a ticket <PRBadge url="https://github.com/superset-sh/superset/pull/4660" />.
- **Read the thread or channel history** on its own for context, so you do not need to paste earlier messages.
- **Search the web with citations** when a request needs current information.
- **Unfurl Paradev task and workspace links** with rich previews when someone shares them in a channel.

**Setting it up:**

1. In the dashboard, go to **Integrations → Slack**.
2. Click **Connect** to install the Paradev Slack app into your workspace (OAuth).
3. Mention `@superset` in any channel, or open a DM with the bot, and describe what you want done.

If you connected Slack before this release, you do not need to do anything: proactive workspace creation is on by default.
