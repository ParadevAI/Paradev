## Sidebar Overhaul <PRBadge url="https://github.com/superset-sh/superset/pull/601" />

- Project thumbnails can show GitHub avatars
- The workspace sidebar collapses to a compact mode with icons only, and the toggle and collapse behave better
- Richer project headers and compact thumbnails
- New layouts, icons, spacing, and sizing for sidebar and list items in many panels

## Workspaces Page <PRBadge url="https://github.com/superset-sh/superset/pull/599" />

- A new workspaces list with search and filters, grouped under project headers with one row per workspace
- Each row shows status, diffs, timestamps, and whether the workspace is opening or can be reopened
- Right-click a project header for a menu: Open in Finder, Project Settings, Close Project
- Click the workspace sidebar header to toggle it, and the workspaces list closes when you select a workspace

## Workspace Status Indicators <PRBadge url="https://github.com/superset-sh/superset/pull/588" />

- Workspaces show the agent's state in 3 colors (amber=working, red=permission needed, green=ready for review)
- The status updates in real time through Claude Code hooks and the OpenCode plugin
- Click behavior: review → idle (acknowledged), permission → working (assumes permission granted)

## PR Status in Changes View <PRBadge url="https://github.com/superset-sh/superset/pull/608" />

The Changes view header now shows a PR status indicator (icon + number) that links to GitHub. The icon color shows the PR state: green for open, violet for merged, red for closed, muted for draft.
