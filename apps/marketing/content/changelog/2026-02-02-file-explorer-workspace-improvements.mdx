## Performance & Memory Leak Fixes

This release focuses on stability and speed across the app.

**Workspace deletion 12x faster** - Deletion now takes ~4-5 seconds, down from ~60 seconds. Terminal shutdowns and cleanup run in parallel, and git worktree removal runs in the background. <PRBadge url="https://github.com/superset-sh/superset/pull/1120" />

**Port scanning performance** - The app now batches port scans per interval, which lowers CPU usage and makes it more responsive <PRBadge url="https://github.com/superset-sh/superset/pull/1134" />

**Memory leak fixes** - Terminal sessions and workspace cleanup no longer leak memory, so long sessions use less of it

**xterm viewport fixes** - The terminal viewport height no longer causes rendering problems <PRBadge url="https://github.com/superset-sh/superset/pull/1133" />

## File Explorer <PRBadge url="https://github.com/superset-sh/superset/pull/1112" />

Browse and manage your project files from the right sidebar. The new file explorer has a tree view, search, and full file operations.

- Create, rename, delete, move, and copy files from context menus
- Show or hide hidden files, and refresh directory listings
- Search files with instant results, and collapse folders in the tree

## Terminal Upgrades

**xterm.js 6.0** - The terminal now uses the latest xterm.js, with better rendering and WebGL support <PRBadge url="https://github.com/superset-sh/superset/pull/1125" />

**Copy without trailing whitespace** - Text you copy from the terminal no longer has trailing spaces, as in iTerm2 <PRBadge url="https://github.com/superset-sh/superset/pull/1104" />

**International keyboard support** - ⌥ key combinations now work on international keyboards (⌥2 = @) <PRBadge url="https://github.com/superset-sh/superset/pull/1127" />

**Session persistence improvements** - Terminal sessions now always persist through the daemon, which is more reliable <PRBadge url="https://github.com/superset-sh/superset/pull/1105" />
