## Bring Your Own Terminal Agents <PRBadge url="https://github.com/superset-sh/superset/pull/5420" />

You can now add your own terminal agents next to the built-in ones, each with its own icon and launch command.

<Video src="/changelog/2026-07-06-custom-agents.mp4" title="Add a custom terminal agent from Settings → Agents" />

- Register any CLI agent and give it a name and icon
- It runs everywhere the built-in agents run
- Polygraph is a new built-in terminal agent <PRBadge url="https://github.com/superset-sh/superset/pull/5422" />

## Redesigned Workspace Activity Strip <PRBadge url="https://github.com/superset-sh/superset/pull/5439" />

The v2 sidebar now shows what each workspace is doing in one compact activity strip.

<Video src="/changelog/2026-07-06-activity-strip.mp4" title="Running agents and open ports shown inline on the workspace item" />

- Running agents and open ports show inline on the workspace item <PRBadge url="https://github.com/superset-sh/superset/pull/5414" />
- Running and PR state persist across restarts, with a Clear Status action <PRBadge url="https://github.com/superset-sh/superset/pull/5349" />
- Sections with live work have more emphasis, so in-progress workspaces stand out <PRBadge url="https://github.com/superset-sh/superset/pull/5416" />
- Agent chips stay hidden unless more than one agent is running <PRBadge url="https://github.com/superset-sh/superset/pull/5445" />

## Fable 5 and Reasoning Effort <PRBadge url="https://github.com/superset-sh/superset/pull/5418" />

Launch agents with the Fable model family and pick a reasoning-effort level from the workspace.

![New workspace dialog: pick the model (Fable, Opus, Sonnet, Haiku) and reasoning effort inline](/changelog/2026-07-06-model-picker.png)

- Fable 5 is available in the copilot, cursor-agent, and opencode model pickers <PRBadge url="https://github.com/superset-sh/superset/pull/5435" />
- The workspace create dialog has a model picker <PRBadge url="https://github.com/superset-sh/superset/pull/5248" />

## Workspace Dock Badge <PRBadge url="https://github.com/superset-sh/superset/pull/5351" />

The macOS dock icon now shows a badge when a workspace has unread activity or needs your attention. You can step away and still know when an agent needs you.

![Paradev dock icon showing an attention badge for workspaces that need you](/changelog/2026-07-06-dock-badge.png)

## Improvements

**Real tables for Automations & Workspaces**: sortable columns, grouped project headers, row context menus, and an overflow fix. <PRBadge url="https://github.com/superset-sh/superset/pull/5454" />

![Automations table with sortable columns, Mine/Team tabs, and run status](/changelog/2026-07-06-automations-table.png)

- **Restored-session separator** - A marker shows where a v2 terminal restored an earlier session <PRBadge url="https://github.com/superset-sh/superset/pull/5448" />
- **Quit Paradev Completely** - A new macOS app menu item to fully quit <PRBadge url="https://github.com/superset-sh/superset/pull/5419" />
- **Configurable port badges** - Choose where v2 port badges open in **Settings → Links** <PRBadge url="https://github.com/superset-sh/superset/pull/5350" />
