## Task List View <PRBadge url="https://github.com/superset-sh/superset/pull/717" />

- Semantic search for tasks, based on embeddings
- A dedicated system to manage task statuses, with custom workflows
- A redesigned tasks interface with a table view and better organization
- Better task filters and sorting by status, priority, and assignee

## Diff Highlights in Scrollbar <PRBadge url="https://github.com/superset-sh/superset/pull/725" />

The diff viewer scrollbar now shows colored markers: green for additions and red for deletions. Use them to move through a diff quickly.

## Shell Environment Fix <PRBadge url="https://github.com/superset-sh/superset/pull/720" />

- On macOS and Linux, the app now reads your shell environment at startup and applies it
- Terminal settings such as PATH and ZDOTDIR are now available when you launch from Finder or Spotlight
- PATH entries merge more reliably, which prevents terminal startup problems

## Scroll to Bottom Button <PRBadge url="https://github.com/superset-sh/superset/pull/700" />

A floating scroll-to-bottom button appears when you scroll up in the terminal. It has a chevron icon and animates in and out smoothly. Its tooltip shows the keyboard shortcut when one is available.
