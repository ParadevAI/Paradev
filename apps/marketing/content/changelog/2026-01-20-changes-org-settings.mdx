## Expanded Changes Sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/858" />

- A new workspace layout with a resizable sidebar that expands and collapses more reliably
- The main content switches cleanly between tab view and changes view
- A placeholder "changes" view, ready for the code review support that comes next

## Organization Settings <PRBadge url="https://github.com/superset-sh/superset/pull/820" />

- Desktop: pick an image file to set the organization logo (preview + upload)
- Organization settings: edit the name, and manage the slug with live availability checks (owner-only)
- Members: invite, view, sort, and manage organization members, with actions that match each role
- Settings navigation now has separate Organization and Members sections, in place of the team layout

## Diff View Improvements <PRBadge url="https://github.com/superset-sh/superset/pull/845" />

- A new toggle shows or hides unchanged regions in the diff viewer
- Hide unchanged lines to focus on the real changes, which makes large diffs easier to read
- The toggle button is in the file viewer toolbar and shows its current state

## Middle-Click to Close Tabs <PRBadge url="https://github.com/superset-sh/superset/pull/853" />

Middle-click a tab to close it, as in a browser.
