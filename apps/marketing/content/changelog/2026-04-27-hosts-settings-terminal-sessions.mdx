**Paradev 2.0 is in open beta.** Enable it under **Settings → Experimental** <PRBadge url="https://github.com/superset-sh/superset/pull/3748" />. You can switch back at any time, and your v1 workspaces and sessions stay where they are.

![Settings → Experimental: Try Paradev v2 toggle and v1 → v2 migration](/changelog/v2-enable-flag.png)

## Remote workspaces

In 2.0, a workspace runs on a host: your own machine or another Paradev device. Point your local app at any Paradev device on the same network (a bigger machine across the room, a cloud VM, a teammate's host) and run workspaces on it as if they were local. The terminal, file editor, and chat all work the same way <PRBadge url="https://github.com/superset-sh/superset/pull/3566" /> <PRBadge url="https://github.com/superset-sh/superset/pull/3606" />, and ports that listen on the remote host show in your sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/3676" />.

![Sidebar with a Cloud workspace group and a remote workspace hover card](/changelog/v2-remote-workspaces.png)

## Reimagined diff view

The new diff viewer feels like a PR review on your machine. You get one infinite-scroll diff with a compact sidebar of changed files, a viewed state for each file <PRBadge url="https://github.com/superset-sh/superset/pull/3715" /> <PRBadge url="https://github.com/superset-sh/superset/pull/3776" />, and ⇧-click and ⌘-click selection across the file list <PRBadge url="https://github.com/superset-sh/superset/pull/3683" />.

![v2 Changes pane: infinite-scroll diff with compact file sidebar and review tab](/changelog/v2-changes-pane.png)

## Paradev CLI

The `superset` CLI is a single static binary that uses the same backend as the desktop app. Sign in with `superset auth login`, then create workspaces, tail terminals, and trigger automations from your shell or CI <PRBadge url="https://github.com/superset-sh/superset/pull/3638" /> <PRBadge url="https://github.com/superset-sh/superset/pull/3640" />.

```bash
curl -fsSL https://superset.sh/cli/install.sh | sh
superset auth login
```

[CLI docs →](https://docs.superset.sh/cli/getting-started)

## A real IDE shell

**Tab → Split → Pane** with drag and drop everywhere: drop a pane on the tab strip to make a tab <PRBadge url="https://github.com/superset-sh/superset/pull/3809" />. One window holds a file tree with git decorations, a file editor, a browser pane that keeps its state across switches, a new terminal (XTerm.js + WebGL, kitty keyboard, OSC links, search), and live-synced data with optimistic updates <PRBadge url="https://github.com/superset-sh/superset/pull/3722" />.

## Migration in place

1.x projects and workspaces move into 2.0 <PRBadge url="https://github.com/superset-sh/superset/pull/3670" />. The migration is safe to run again for an org <PRBadge url="https://github.com/superset-sh/superset/pull/3775" /> <PRBadge url="https://github.com/superset-sh/superset/pull/3781" /> <PRBadge url="https://github.com/superset-sh/superset/pull/3783" />, and the migration modal shows only the first time you onboard <PRBadge url="https://github.com/superset-sh/superset/pull/3816" />.
