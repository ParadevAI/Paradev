This update covers the last three weeks. Chat has a new rich-text prompt editor, chips for slash commands and file mentions, and redesigned tool calls. The v2 workspace is now in early access, with panes, a diff viewer, a file editor, a review tab, and a browser pane. The Paradev CLI shipped, and a self-contained tarball runs the host service without the desktop app. The desktop app has a new logo and icons, and GitHub integration is now free on every plan.

## Chat UX overhaul <PRBadge url="https://github.com/superset-sh/superset/pull/3039" />

### Tiptap prompt input

The prompt is now a rich text editor with inline chips for commands and file references.

- **Slash command chips**: type `/` to open a command menu. The command becomes an inline chip anywhere in the message and no longer submits at once. A chip that takes an argument has an inline input that resizes as you type and works with the keyboard. `/model` shows a dropdown of available models.
- **File mention chips**: type `@` to search files at the cursor. Pick a file to insert a chip, which sends as `@path`.
- **Skill preload**: a `/command` chip loads the right skill before the model reads your message. A row in the message shows the skill while it loads.
- **Preview on hover**: hover a chip to see its description (hidden while you edit the chip's argument).
- Enter does not submit while CJK (IME) input is pending. Tab no longer selects a command: use Enter or a click.

### Redesigned tool calls

- A compact, monospaced layout for tool input, output and headers, with a braille spinner and icons on the left
- Subagent activity shows inline as a collapsible tool call, with full markdown for the task prompt and response
- Click the file name on any file tool call (read, write, LSP inspect) to open the file in the editor pane
- Read-file output has syntax highlighting, a filename header and a line-range label. Every code block has expand/collapse and copy

### ask_user flow

- Questions show in a footer overlay with a pinned header and footer and scrollable option buttons, not inline in the message
- Status chips (Awaiting Response / Answered / Cancelled) with a collapsible answer bubble. Cancelled shows as soon as you abort
- The question closes as soon as you submit, and focus returns to the prompt
- Paradev now asks every question through `ask_user`, with no plain-text fallback

### Workspace status and notifications

- A pending question puts an orange dot on the workspace nav and sends a native OS toast, even when the tab is not in focus
- The orange dot clears as soon as you submit an answer
- Chat scrolls to the bottom when you send a message, when a question arrives, and when you submit an answer

## The v2 workspace is in early access

## Paradev CLI <PRBadge url="https://github.com/superset-sh/superset/pull/3194" />

{/* TODO: Screenshot of the CLI in action */}

The `superset` CLI lets you manage Paradev from your terminal. It ships as a self-contained tarball <PRBadge url="https://github.com/superset-sh/superset/pull/3298" />, so you can run the host service on a remote server, CI box, or cloud VM without the desktop app.

```bash
tar -xzf superset-darwin-arm64.tar.gz -C ~/superset
export PATH="$HOME/superset/bin:$PATH"

superset auth login              # OAuth PKCE + loopback
superset host start --daemon     # connects to relay.superset.sh
superset tasks list              # full task CRUD
superset org switch              # manage organizations
```

Binaries are available for macOS (arm64, x64) and Linux x64. Use `--json` output for scripts and agents.
