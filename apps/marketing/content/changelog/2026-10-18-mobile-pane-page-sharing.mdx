## A Mobile Pane for Simulators and Emulators <PRBadge url="https://github.com/superset-sh/superset/pull/8280" />

Run your app on an iOS simulator or Android emulator in a pane beside the agent that is building it.

- Pick any simulator or emulator from the device menu; a shut-down device boots when you choose it
- Home, Screenshot, and Rotate keys under the screen, plus Back and Recent apps on Android and Reload for React Native apps

Press ⌘⇧M to split the current pane with a mobile simulator. You need Xcode for iOS or the Android SDK for Android.

## Share Pages with People and Teams <PRBadge url="https://github.com/superset-sh/superset/pull/8318" /> <PRBadge url="https://github.com/superset-sh/superset/pull/8317" />

A page no longer has to be private or visible to the whole org. Share it with one teammate, a team, or someone outside your org, and choose what they can do.

- Give each person **Can view** or **Can comment**, and set general access to only invited people, your org, or anyone with the link
- People outside your org get an invite, and their access starts when they join
- Pages shared with you collect under a new **Shared with me** tab
- Comments can carry up to four images: attach, paste, or drag them in, and agents reading the thread can fetch the screenshot <PRBadge url="https://github.com/superset-sh/superset/pull/7875" />

Open a page and click **Share** to invite someone.

## Pull Request Activity Timeline <PRBadge url="https://github.com/superset-sh/superset/pull/8398" /> <PRBadge url="https://github.com/superset-sh/superset/pull/8428" /> <PRBadge url="https://github.com/superset-sh/superset/pull/8429" />

The pull request page's comments section is now an **Activity** rail: comments, reviews, review threads, and commits in one stream, oldest first.

- Reply to a review thread from the rail, and long comments fold behind **Show more**
- Resolved and outdated threads fold to a single line, so open threads stay on top
- GitHub pull request links in chat, markdown, pages, and the terminal open the pull request pane instead of a browser

![A pull request page with the Activity rail highlighted: pushed commits and a review comment in one stream](/changelog/2026-10-18-pr-activity.png)

## Add a Host over SSH <PRBadge url="https://github.com/superset-sh/superset/pull/8396" />

Go to **Settings → Hosts → Set up a host over SSH**, enter the SSH destination, and Superset installs and registers the host in an embedded terminal. Passwords, MFA, and host-key prompts work as in any terminal. From a terminal, the same thing is one command:

```bash
superset hosts add user@my-box
```

![The Set up a host over SSH dialog over Settings → Hosts, with an SSH destination entered](/changelog/2026-10-18-host-over-ssh.png)
