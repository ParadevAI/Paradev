## Pull Requests, Open to Everyone <PRBadge url="https://github.com/superset-sh/superset/pull/6710" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6715" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6716" />

The Pull Requests page is now a split view: a resizable list on the left and the PR you clicked on the right. Collapse either side to give the other the full width. Merge (squash, merge, or rebase), close, and reopen a PR from the detail header without leaving Paradev.

- Filter by repository, author, and review state; tabs for All, Open, and Merged
- The detail header leads with the title, then state, author, number, age, and a copyable branch name
- Cancelled CI runs now count as failed instead of showing green <PRBadge url="https://github.com/superset-sh/superset/pull/6611" />

Pull Requests no longer requires a paid plan. Open it from **Pull requests** in the sidebar on any account.

![The Pull Requests split view with the list on the left and an open PR with Merge and Add to workspace actions on the right](/changelog/2026-08-23-pull-requests-split.png)

## Multiple Windows <PRBadge url="https://github.com/superset-sh/superset/pull/5337" />

Open a second window with **File → New Window** and watch more than one workspace at a time, one per screen. Each window can also pin its own organization, so two orgs can sit side by side. Switching org in one window does not change another, the title names the org, and open windows come back on relaunch. Contributed by [@ashbrener](https://github.com/ashbrener).

![Two Paradev windows side by side, one running Claude Code on a pull request workspace and one running OpenCode on another](/changelog/2026-08-23-multi-window.png)

## Design Mode in the Browser Pane <PRBadge url="https://github.com/superset-sh/superset/pull/6695" />

Point at a UI element instead of describing it to an agent. Click **Design** in the browser pane toolbar, pick any element on the page, and a prompt card opens under it. Send it, and the agent gets your note with the element's DOM, styles, React component info, and a cropped screenshot. It goes to an existing agent terminal or a new session.

<Video src="/changelog/2026-08-23-design-mode.mp4" title="Design mode picking the hero on superset.sh and sending it to Claude with full element context" />

## Bring Your Chrome Into the In-App Browser <PRBadge url="https://github.com/superset-sh/superset/pull/6691" />

**Settings → Browser** now has **Import from Chrome**. Copy browsing history and logins from Chrome, Edge, Brave, Arc, Dia, or Comet into Paradev's browser pane, per profile, so pages your agents open are already signed in. The same section sets the browser homepage. You can also run the import from the CLI:

```bash
superset browser import-login
```

![The Import settings from another browser dialog listing Chrome, Edge, Brave, Arc, Dia, and Comet profiles with history and logins checked](/changelog/2026-08-23-browser-import.png)

## Agent Sessions Resume Themselves <PRBadge url="https://github.com/superset-sh/superset/pull/6572" />

When an agent's terminal dies (reboot, killed daemon, crashed process), the pane now resumes the session on its own and shows a "Resuming…" pill. You no longer need to click Resume. Only one session comes back, no matter how many panes or windows notice at once.

## Track Usage Across Agents and Accounts <PRBadge url="https://github.com/superset-sh/superset/pull/6585" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6567" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6645" />

The Usage tab now shows every Claude Code and Codex login side by side: live session and weekly quotas for each account, a chart of token spend over time, and the cost of each workspace. Add a second subscription as its own profile and pick the account new agents start with, so you can switch when one hits its limit.

- Profiles share your skills, MCP servers, settings, and conversation history, so you keep your whole setup when you switch accounts
- An expired login shows the exact sign-in command to copy <PRBadge url="https://github.com/superset-sh/superset/pull/6628" />
- Machine resources are in the same tab behind a pill toggle: CPU and memory per process, with click-to-navigate

![The Usage tab with two Claude Code accounts, quota bars per account, and a token spend chart](/changelog/2026-08-23-usage-accounts.png)

Open **Usage** in the sidebar.

## Improvements

- **Pages** - publish a self-contained HTML file from the CLI, an agent, or MCP and get a stable URL with version history; readers pin comments to any element, and you can hand a thread to an agent to answer in place. `superset pages publish report.html` <PRBadge url="https://github.com/superset-sh/superset/pull/6806" />
- **Workspaces board controls** - hide any lane from the Display menu, filter by pinned or unpinned, and the toolbar's seven dropdowns are now two menus, Filter and Display <PRBadge url="https://github.com/superset-sh/superset/pull/6568" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6561" />
- **New workspace composer grows with your prompt** - up to half the screen before it scrolls, and you can drag either edge to widen it on both sides <PRBadge url="https://github.com/superset-sh/superset/pull/6746" />
- **⌘⇧N creates a workspace instantly** - in the current project, with no dialog <PRBadge url="https://github.com/superset-sh/superset/pull/6727" />
- **Automations start on their page** - New automation opens an untitled automation at once; name it, write instructions, and add triggers on one page instead of in a modal <PRBadge url="https://github.com/superset-sh/superset/pull/6713" />
- **Cloud workspaces open right away** - the workspace opens at once and setup finishes in the background <PRBadge url="https://github.com/superset-sh/superset/pull/6566" />
- **Image paste in remote and cloud terminals** - pasted images upload into the workspace and paste as a path, so Claude Code and Codex on another machine can read them <PRBadge url="https://github.com/superset-sh/superset/pull/6692" />
- **Two new themes** - Obsidian by [@joaobnobre](https://github.com/joaobnobre) and Tokyo Night Blackout by [@talarczykco](https://github.com/talarczykco), both on the [marketplace](https://superset.sh/marketplace) <PRBadge url="https://github.com/superset-sh/superset/pull/6638" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6095" />
- **Agent skills for desktop and browser control** - a `superset:computer` skill drives native apps through Cua Driver, contributed by [@f-trycua](https://github.com/f-trycua), and the browser skill can now use Browser Use 3.0 for pages the in-app pane can't reach <PRBadge url="https://github.com/superset-sh/superset/pull/6644" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6646" />
- **Billing grace period** - a declined card no longer drops you to the free plan on the first retry; paid access stays on while Stripe keeps trying <PRBadge url="https://github.com/superset-sh/superset/pull/6732" />
- **iOS** - a pull request screen with merge, checks, and reviewers, working actions on every PR card, a native composer, tappable links and text selection in the terminal, and a native attachments sheet, all in the next App Store build <PRBadge url="https://github.com/superset-sh/superset/pull/6491" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6796" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6761" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6685" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6688" />

- **Experimental: ports in the top bar** - a pill opens a dropdown of the workspace's running dev servers, under **Settings → Experimental** <PRBadge url="https://github.com/superset-sh/superset/pull/6684" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6726" />
