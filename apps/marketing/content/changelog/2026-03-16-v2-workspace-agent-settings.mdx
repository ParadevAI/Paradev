## Configurable Agent Settings <PRBadge url="https://github.com/superset-sh/superset/pull/2495" />

You can now configure agent behavior in the desktop settings. Override built-in presets, preview prompt templates, and reuse the same agent definitions everywhere you launch work, with no config files to edit by hand.

- Adjust model, labels, descriptions, commands, and prompt templates from one settings page
- Changes save immediately, and you can reset them to defaults
- The same shared agent presets now drive workspace creation and task launch

## Simpler Workspace Modal <PRBadge url="https://github.com/superset-sh/superset/pull/2391" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2506" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2500" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2513" />

The workspace modal now keeps project selection, prompts, images, PRs, and issues in one flow, so you can launch a workspace with full context faster.

![New workspace modal](/changelog/new-workspace-modal-2026-03-16.png)

- Prompt-first creation flow with project selection built into the modal
- Project avatars, GitHub owner details, and inline `Add from GitHub` in the selector
- Prompt text, image attachments, linked PRs, linked issues, and the selected agent all sit in the same flow
- Prompt text, attachments, and selected agent persist when you close and reopen the modal
- Branch prefix previews, better long-name truncation, and PR lookup by pasted GitHub URL

## Tab and Pane Enhancements <PRBadge url="https://github.com/superset-sh/superset/pull/2488" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2487" />

Desktop layouts are more flexible now. Drag a whole tab into another pane layout to merge it, and rename pane headers inline to keep dense workspaces organized.

![Drag tab into pane](/changelog/drag-tab.png)

- Drag a top-level tab onto another tab's split zones to merge it left, right, top, or bottom
- The source tab closes after the merge, and pane ownership and layout state stay intact
- Double-click a pane header to rename it in place
