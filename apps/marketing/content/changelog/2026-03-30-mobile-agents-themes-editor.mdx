## Mobile Agents Experience (WIP) <PRBadge url="https://github.com/superset-sh/superset/pull/2595" />

We're building a mobile-first agents experience in the web app. It's still a work in progress, but you can already browse, start, and monitor agents from your phone, in an interface made for smaller screens. More to come here.

## SOC 2 Compliance & Pen Test Passed

Paradev now passes its independent penetration test and meets SOC 2 compliance requirements. We shipped a round of security hardening based on the pen test findings. This matters for teams that need enterprise-grade security assurances.

## Theme Marketplace <PRBadge url="https://github.com/superset-sh/superset/pull/2966" />

![Theme Marketplace](/changelog/marketplace.png)

Browse and install themes from the new theme marketplace. When your system is in auto mode, you can now pick separate themes for light and dark <PRBadge url="https://github.com/superset-sh/superset/pull/2557" />.

## Improvements
- **Open in editor from worktrees** - Jump straight from a worktree into your external editor <PRBadge url="https://github.com/superset-sh/superset/pull/2999" />
- **⌘-click file paths** - ⌘-click a file path in chat or output to open it in your editor <PRBadge url="https://github.com/superset-sh/superset/pull/2903" />
- **New workspace modal UX** - Cleaner layout with icon buttons and server-side PR search <PRBadge url="https://github.com/superset-sh/superset/pull/2980" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2909" />
- **Close workspace hotkey** - ⌘W closes a workspace <PRBadge url="https://github.com/superset-sh/superset/pull/2907" />
- **Settings search indicator** - Settings shows an indicator when a search filter is active <PRBadge url="https://github.com/superset-sh/superset/pull/2997" />
- **Terminal flow control** - Hardened backlog and flow control, so the terminal does not drop output under heavy load <PRBadge url="https://github.com/superset-sh/superset/pull/3006" />
