## Review Tab in Changes Sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/2681" />

The changes sidebar now has a dedicated Review tab. You can read, filter, and respond to PR review comments without leaving the desktop app.

- Resolved comments sit apart from open ones, so you can focus on what still needs attention
- Stays in sync with GitHub and refreshes automatically after PR changes

## Task Create & Detail Actions <PRBadge url="https://github.com/superset-sh/superset/pull/2656" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2660" />

![Task create modal](/changelog/create-task.png)

You can now create tasks and act on them from the desktop, without a switch to Linear or the web app.

- New task create modal to file a task from wherever you are
- Task detail action menu for quick actions on a single task

## Project-Level Presets Configurable <PRBadge url="https://github.com/superset-sh/superset/pull/2719" />

![Project-level presets](/changelog/project-presets.png)

You can now scope terminal presets to one project. Project-level presets appear only when you work in that project, so the preset list stays short and relevant.

## Run Button & Stop Command <PRBadge url="https://github.com/superset-sh/superset/pull/2680" /> <PRBadge url="https://github.com/superset-sh/superset/pull/2740" />

![Run button](/changelog/run-button.png)

The run button is now in the presets bar (⌘G) and has a stop command, so you can cancel a running preset.

- ⌘G triggers the run preset from anywhere in the workspace
- Stop button cancels in-progress runs immediately

## Improvements

- **AI-generated branch names** - Paradev now suggests a branch name when you create a workspace, and resolves the conflict automatically if a branch already has that name <PRBadge url="https://github.com/superset-sh/superset/pull/2627" />
- **Chat draft preserved** - Unsent chat text is now saved when you switch tabs or workspaces and restored when you come back <PRBadge url="https://github.com/superset-sh/superset/pull/2631" />
- **Warn before closing dirty editors** - Desktop now prompts before closing a file tab with unsaved changes <PRBadge url="https://github.com/superset-sh/superset/pull/2717" />
- **GitHub issue attachment in workspace modal** - Attach a GitHub issue in the new workspace modal to give the agent context from the start <PRBadge url="https://github.com/superset-sh/superset/pull/2678" />
- **Autosave for setup/teardown scripts** - Setup and teardown scripts now save automatically as you edit them <PRBadge url="https://github.com/superset-sh/superset/pull/2644" />
- **⌘R reload now configurable** - Remap or turn off the ⌘R reload shortcut in keyboard settings <PRBadge url="https://github.com/superset-sh/superset/pull/2716" />
- **Virtualized git history** - The git history panel now caps the commit list at 500 and renders only the visible rows, which prevents slowdowns in repos with long histories <PRBadge url="https://github.com/superset-sh/superset/pull/2763" />
- **PR merge loading feedback** - The merge button now shows a loading state while a PR merges <PRBadge url="https://github.com/superset-sh/superset/pull/2703" />
