## Stacked Pull Requests and Merge Queues <PRBadge url="https://github.com/superset-sh/superset/pull/9554" />

A pull request in a stack now merges with the layers below it. The merge button reads **Merge stack**, names how many pull requests it lands, and lists each one before you confirm.

- **Merge queue** - add a pull request or a whole stack to the base branch's merge queue, see its position, and remove it again
- **Stack chip** - click the chip (for example **2/4**) for one verdict, the reason a merge is blocked, and a status for each layer
- **Restack** - shown when your branch still carries a layer that already merged below it
- Merge buttons offer only the methods your repository allows, with its default first <PRBadge url="https://github.com/superset-sh/superset/pull/9527" />

Open a stacked pull request from **Pull requests** in the sidebar. Docs: [Pull Requests](https://docs.paradev.com/pull-requests).

## Any Agent Session in Chat or Terminal <PRBadge url="https://github.com/superset-sh/superset/pull/9529" />

Every agent pane can now open its session in the other view. Click the pane title and pick **Fork into Chat** on a terminal, or **Fork into CLI** on a chat. The copy opens in a new tab <PRBadge url="https://github.com/superset-sh/superset/pull/9581" />.

![The chat pane title menu, with Fork into CLI and Fork into Chat at the bottom](/changelog/2026-11-15-fork-chat-terminal.png)

- The pane title menu also holds new, rename, sessions and account usage
- The approval card shows why Claude Code asks, even in Full access <PRBadge url="https://github.com/superset-sh/superset/pull/9574" />
- New chats remember fast mode for each agent <PRBadge url="https://github.com/superset-sh/superset/pull/9531" />

**Settings → General → Open agents in chat** now only picks what new sessions start as.

## Drag Tabs and Panes Between the Main Area and the Sidebar <PRBadge url="https://github.com/superset-sh/superset/pull/9530" />

Any tab or pane moves between the main area and the right sidebar, in both directions. Drop it on a tab bar, on a pane to split it, or on an empty area.

- ⌘⌃← and ⌘⌃→ switch the sidebar tab without moving focus
- ⌘⌥L moves focus between the main tabs and the sidebar

## Cloud Workspaces Show Their Load

A cloud workspace that runs out of CPU or memory now shows a dot in the sidebar. Hover it to see the usage and the process that was stopped <PRBadge url="https://github.com/superset-sh/superset/pull/9709" />.

- **Change machine size** - right-click a cloud workspace and pick **Machine size**
- **Set up an environment from chat** - a project with no cloud environment gets a **Set up Environment** chip on the new-workspace screen, and an agent builds it for you <PRBadge url="https://github.com/superset-sh/superset/pull/9707" />
- **Ports button** - forwarded ports get their own button beside **Share** <PRBadge url="https://github.com/superset-sh/superset/pull/9642" />
- A sleeping cloud workspace opens on its chats while the machine wakes <PRBadge url="https://github.com/superset-sh/superset/pull/9565" />

![The right-click menu on a cloud workspace, with the Machine size submenu showing Small, Medium and Large](/changelog/2026-11-15-cloud-machine-size.png)

Docs: [Cloud Workspaces](https://docs.paradev.com/cloud-workspaces).
