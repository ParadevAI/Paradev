## Commit, Push, and Create a PR From the Changes Pane <PRBadge url="https://github.com/superset-sh/superset/pull/7102" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7139" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7166" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7196" />

The Changes pane now holds the whole branch in one place: the diff, the list of changed files, and every step to a pull request. A pill in the top bar shows the diff stats. The control next to it steps from Commit to Push to Create PR, then becomes the PR badge when the pull request exists.

- Commit opens a message popover with a generated fallback message. Create PR fills in the title from your latest commit and pushes an unpublished branch for you
- Reply to PR review threads in the diff, without opening GitHub
- Search the changed files by path; a renamed file also matches its old path

Open it with ⌘⇧L or the diff pill in the top bar.

## Image, Video, and PDF Diffs <PRBadge url="https://github.com/superset-sh/superset/pull/7035" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7182" />

Binary files in the Changes pane open in the same viewers as the file pane. A modified image shows Before and After side by side. Both use the version the diff compares (staged, against base, or a commit), not only the working tree. Videos and PDFs load when you click Preview, so a large changeset stays light. [@theblondealex](https://github.com/theblondealex) contributed the image previews.

## Workspaces Page Rebuilt Around Devices <PRBadge url="https://github.com/superset-sh/superset/pull/6901" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7150" />

The page title is now the device you are looking at, and your other hosts are one click away. Every row shows its machine, dimmed when that device is offline.

- Filter by project and by who created the workspace, next to the search box
- Board cards are simpler: a muted project line, a state icon beside the title, and a footer with PR, churn, and activity age
- Search and filters respond instantly, even with hundreds of workspaces
- Main checkouts with a finished agent show in Needs review, as they do elsewhere in the app <PRBadge url="https://github.com/superset-sh/superset/pull/7142" />

## New Models and Reasoning Levels <PRBadge url="https://github.com/superset-sh/superset/pull/7099" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7137" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7045" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7178" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6805" />

Claude Fable 5.1 and GPT-6 Astra are in the model pickers and the usage pricing table. Codex offers its max and ultra reasoning levels on the models that accept them, and Cursor Agent has its own reasoning effort picker. You can also pick a model for each launch from the CLI, the SDK, and MCP, contributed by [@Shravankb301](https://github.com/Shravankb301):

```bash
superset agents create --workspace W --agent claude --model claude-fable-5-1
superset ws create --agent codex --model gpt-6-astra
```
