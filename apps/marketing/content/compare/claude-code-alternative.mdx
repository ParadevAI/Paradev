Claude Code is Anthropic's coding agent. It has the widest range of parallel modes of any agent, with subagents, `/batch` runs across worktrees, cloud sessions, and Remote Control, but it needs a paid Claude plan or an API key and runs only Anthropic's models. Other strong agents now exist, and the best one for a task can change from one release to the next. Superset lets you keep Claude Code and run any of these alternatives beside it, each in its own Git worktree, so you can compare the diffs on your own code.

**Our recommendation: keep Claude Code, and use Superset to try the alternatives side by side on the same task.** The list below covers the agents worth trying, from free and open-source options to other labs' agents.

## Why Look for a Claude Code Alternative?

Claude Code is strong for deep, multi-step work. Common reasons to look further:

- **Cost.** There is no free tier, and Anthropic warns that parallel runs multiply token use.
- **Models.** You want GPT, Gemini, open-weight, or local models.
- **Open source.** You want an agent you can read and change.
- **A second opinion.** A different agent often solves the task Claude Code is stuck on.
- **Vendor risk.** You do not want your whole workflow to depend on one lab.

## The Best Alternatives

### Codex CLI

OpenAI's agent is open source under Apache-2.0 and comes with ChatGPT plans, so one subscription covers the CLI, the IDE extension, the ChatGPT desktop app, cloud tasks, and code review. It has subagents, worktrees, `codex exec` for CI, an SDK, and a GitHub Action. It is the closest like-for-like alternative to Claude Code.

See [Claude Code vs Codex](/compare/claude-code-vs-codex) and [Superset vs Codex](/compare/superset-vs-codex).

### Antigravity CLI

Google's `agy` shares its agent harness with the Antigravity desktop app, runs async subagents that can each take a worktree, and is free with weekly limits. It includes Gemini, Claude, and gpt-oss models, so it is the cheapest way to keep using Claude models in a different agent.

See [Claude Code vs Antigravity CLI](/compare/claude-code-vs-antigravity-cli) and [Superset vs Google Antigravity](/compare/superset-vs-antigravity).

### OpenCode

OpenCode is the most popular open-source agent with free choice of provider. It has a terminal UI, a desktop app, an IDE extension, built-in subagents, and a server with an SDK. It is MIT-licensed and free; you pay only for the models.

See [Claude Code vs OpenCode](/compare/claude-code-vs-opencode) and [Superset vs OpenCode](/compare/superset-vs-opencode).

### GitHub Copilot CLI

Copilot's terminal agent offers models from several vendors, including Claude, on one plan, starting with a free tier. Issues, pull requests, and the GitHub MCP server are built in, and `/delegate` hands work to Copilot's cloud agent.

See [Claude Code vs Copilot CLI](/compare/claude-code-vs-copilot-cli) and [Superset vs GitHub Copilot](/compare/superset-vs-github-copilot).

### Amp

Amp picks models for you by mode, runs work on "orbs," cloud machines that keep going after you close your laptop, and runners that create Git worktrees. It is free with your own compute and keys, and since October 2026 it can use a Claude Pro or Max plan.

See [Claude Code vs Amp](/compare/claude-code-vs-amp) and [Superset vs Amp](/compare/superset-vs-amp).

### Cursor CLI

Cursor's terminal agent shares worktrees, rules, and MCP config with the Cursor editor and its Cloud Agents. Choose it if you already pay for Cursor.

See [Claude Code vs Cursor CLI](/compare/claude-code-vs-cursor-cli) and [Superset vs Cursor](/compare/superset-vs-cursor).

### Superset (to run them all)

Superset is not an agent. It is a desktop workspace that runs Claude Code and every agent above, each in its own Git worktree and terminal, on your own subscriptions and keys; Superset never proxies model calls. You can also continue a stuck session with a different agent, schedule agents as automations, and check on them from the [iPhone and iPad app](/mobile).

See [Superset vs Claude Code](/compare/superset-vs-claude-code).

## How To Choose

- For the closest like-for-like agent from another lab, choose **Codex CLI**.
- For a free start that still includes Claude models, choose **Antigravity CLI**.
- For open source with any model, choose **OpenCode**.
- For GitHub-centric teams on one low-cost plan, choose **Copilot CLI**.
- To let the vendor pick the model, choose **Amp**.
- To compare any of them with Claude Code on your own repository, use **Superset**.

## Frequently Asked Questions

### What is the best Claude Code alternative?

Codex CLI is the closest like-for-like alternative: an open-source agent from a major lab with subagents, worktrees, and cloud tasks. OpenCode is the best open-source option for any model, and Antigravity CLI is the best free start.

### Is there a free Claude Code alternative?

Yes. Antigravity CLI is free with weekly limits, Copilot CLI has a free tier, Codex includes limited use on ChatGPT Free, and OpenCode and Amp are free with your own model keys.

### Is there an open-source Claude Code alternative?

Yes. Codex CLI (Apache-2.0) and OpenCode (MIT) are open source. Claude Code is proprietary.

### Can I use Claude Code and an alternative together?

Yes. Superset runs Claude Code and other CLI agents side by side, each in its own Git worktree, so they cannot overwrite each other's files. You pay each provider for its own usage.
