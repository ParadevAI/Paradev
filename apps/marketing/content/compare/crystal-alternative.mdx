Crystal was an MIT-licensed desktop app for running Claude Code and Codex sessions in parallel Git worktrees, with in-app diff review and Git operations. Its repository now says "Crystal Is Now Nimbalyst": the last Crystal release, v0.3.5, shipped on February 26, 2026, and active development moved to Nimbalyst. If you are moving off Crystal and want more than Claude Code and Codex, Superset runs any CLI agent in the same worktree-per-task model, with review, a browser, and automations around it.

**Our recommendation: choose Superset if you want Crystal's worktree model with any agent, PR review, and remote and cloud workspaces.** If you want the direct successor, choose Nimbalyst.

[Download Superset](/download) to try a small task, or read [Superset vs Crystal](/compare/superset-vs-crystal) for the direct comparison. This guide is published by Superset; recommendations describe workflow fit rather than benchmark results.

## Why Look for a Crystal Alternative?

- **No more releases.** Crystal's last release shipped in February 2026, and new agent versions will not get fixes there.
- **More agents.** Crystal runs Claude Code and Codex. You may also use OpenCode, Cursor's agent, Copilot CLI, Gemini CLI, or Amp.
- **Reach.** Crystal is a local desktop app. You may want agents on other machines or in the cloud, and a phone app.
- **Unattended work.** You may want scheduled agent runs.

## The Best Alternatives

### Superset

Superset runs any CLI agent, including Claude Code and Codex, each in its own Git worktree with persistent terminal sessions. Like Crystal, it keeps review in the app: the Changes pane commits, pushes, and opens PRs, and the PR pane shows checks, review threads, and merge. It adds an in-app browser with Design Mode, port management, and a Workspaces page that shows which agents need you. Workspaces run on your machine, on hosts you add through Remote Access, or in cloud workspaces, and the [iPhone and iPad app](/mobile) reaches all of them. Pro adds remote access, the iPhone and iPad app, and scheduled automations, and a CLI, TypeScript SDK, and MCP server let agents start other agents.

For the direct comparison, see [Superset vs Crystal](/compare/superset-vs-crystal).

### Nimbalyst

Nimbalyst is where Crystal's development continues. It is an MIT-licensed visual workspace for Claude Code, Codex, and OpenCode on macOS, Windows, and Linux, with iOS and Android companions. It runs agents in parallel and adds visual editing of markdown, mockups, and diagrams, plus task tracking. Choose it if you liked Crystal and want the same team's next product.

See [Superset vs Nimbalyst](/compare/superset-vs-nimbalyst).

### Orca

Orca is a free, MIT-licensed desktop agent development environment for macOS, Windows, and Linux. It runs Claude Code, Codex, and many other agents in parallel worktrees with per-task browser tabs, Design Mode, SSH worktrees, scheduled automations, and beta mobile apps.

See [Superset vs Orca](/compare/superset-vs-orca).

### Emdash

Emdash is an Apache-2.0 desktop app for macOS, Windows, and Linux that supports 34 CLI agents. It gives each task its own branch and worktree, pulls tasks from Linear, Jira, GitHub, Notion, and Asana, and supports SSH machines and scheduled runs.

See [Superset vs Emdash](/compare/superset-vs-emdash).

### Conductor

Conductor is a Mac app that runs Claude Code, Codex, Cursor, and OpenCode in parallel workspaces. Its Pro plan at $50/month adds cloud workspaces, multiplayer, an API, and an iOS app.

See [Superset vs Conductor](/compare/superset-vs-conductor).
