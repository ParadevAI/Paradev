Claude Code is Anthropic's terminal coding agent. Antigravity CLI, run as `agy`, is Google's, and it replaced Gemini CLI for most users in May 2026. Both read your code, run commands, split work across subagents, and take MCP servers, hooks, plugins, and skills. The biggest differences are price and models: Antigravity CLI is free to start and runs Gemini, Claude, and gpt-oss models, while Claude Code needs a paid Claude plan and runs Claude only.

Facts were checked against Anthropic's and Google's own docs on October 13, 2026.

## What Is Claude Code?

Anthropic describes Claude Code as "an agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools." It has the widest set of parallel modes of any agent: subagents, `/batch` runs that fan a change out across worktrees, an agent view for background sessions, experimental agent teams, cloud sessions, and Remote Control. Plugins with marketplaces, skills, and hooks make it highly extensible. It is not on Claude's free plan; it comes with Pro, Max, Team, and Enterprise, or an API key.

## What Is Antigravity CLI?

Google's `agy` "brings the reasoning, execution, and orchestration capabilities of Antigravity agent harness directly into your terminal." It shares its harness and synced settings with the Antigravity 2.0 desktop app, and you can export a conversation from the terminal to the app. It runs async subagents, which can each take an isolated worktree, background shell tasks, and agent teams in preview on paid plans. Individuals get it free with weekly limits, and Google AI Pro and Ultra raise them. Google notes there is no one-to-one feature parity with Gemini CLI, which still exists for paid API and Code Assist users.

## Key Differences

### Price

Antigravity CLI is the easier start: it is free with weekly limits. Claude Code needs a paid Claude plan or API spend from the first prompt.

### Models

Claude Code runs Anthropic's models. Antigravity CLI runs Google's Gemini models by default and also offers Claude Sonnet and Opus and gpt-oss, though Google gives non-Gemini models a separate, fixed rate limit. If you want Claude inside Google's harness, Antigravity offers it; if you want Claude in Anthropic's own harness, that is Claude Code.

### Parallel Work

Both run subagents and both can isolate them in worktrees. Claude Code has more built-in modes for parallel work today, including `/batch` and an agent view for background sessions. Antigravity CLI's agent teams are still in preview.

### Desktop Pairing

Antigravity CLI pairs with Google's Antigravity desktop app and shares its settings. Claude Code pairs with Claude's own apps and IDE extensions.

**Choose Claude Code if you:**

- Already pay for Claude Pro or Max
- Do deep, multi-step work on large codebases

**Choose Antigravity CLI if you:**

## Frequently Asked Questions

### Is Antigravity CLI the same as Gemini CLI?

No. Antigravity CLI (`agy`) replaced Gemini CLI for free, Google AI Pro, and Google AI Ultra users in 2026. Gemini CLI is still released and works with paid API keys and Code Assist licenses. Superset runs both.

### Is Antigravity CLI free?

Yes, with weekly limits. Google AI Pro and Ultra plans raise them. Claude Code has no free tier.

### Can Antigravity CLI use Claude?

Yes. Antigravity offers Claude Sonnet and Opus models inside its own harness, with a separate rate limit.

### Can I run Claude Code and Antigravity CLI at the same time?

Yes. Give each its own Git worktree so they do not edit the same files. In Superset, each runs in its own workspace on the same repository.
