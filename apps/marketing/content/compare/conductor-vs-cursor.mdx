## What Is Conductor?

Conductor is a native macOS app from Melty Labs for running Claude Code, Codex, and Cursor agents in parallel, each in an isolated workspace backed by a Git worktree. It centers on a clean review-and-merge and pull-request flow: dispatch agents, review their diffs, and merge the ones you want. It is Mac only and reuses your existing agent subscriptions.

Conductor is joining Meta, announced on November 4, 2026. It no longer takes new sign-ups or sells plans, and existing Pro users keep Pro features for free. The local Mac app gets new models and critical bug fixes until early 2027, then winds down. Conductor Cloud goes read-only on November 13, 2026 and shuts down on November 20, 2026. If you use Conductor today, see [Migrate from Conductor](https://docs.paradev.com/migrate-from-conductor) for the local Mac app and [Migrate from Conductor Cloud](https://docs.paradev.com/migrate-from-conductor-cloud) for cloud workspaces.

## What Is Cursor?

Cursor is an AI-first fork of VS Code. Its agent mode reads the codebase, edits across files, and runs terminal commands, and Cursor 2.0 added a multi-agent interface that runs up to eight agents in parallel, each in its own local Git worktree, plus background agents in the cloud. It is a full editor with its own models (including Composer) and runs on macOS, Windows, and Linux. Pricing starts with a free tier and Pro at $20/month, up to higher Ultra and team tiers.

## Conductor vs Cursor: Key Differences

### Orchestrator vs Editor

Conductor is an orchestration layer: you do not primarily type code in it, you dispatch agents and review results. Cursor is an editor: you work in it directly, with an agent that can take over tasks. Conductor sits around agents; Cursor is the agent-and-editor in one. Conductor can run Cursor's agent, so they are not mutually exclusive.

### Parallel Isolation

Both run parallel agents in local Git worktrees, which is a recent and important convergence. Conductor is built around that as its whole purpose. Cursor added it as a feature inside the editor (up to eight agents to compare results). Conductor's focus showed when parallel isolation was the entire point of a workflow. If you want it inside a full editor, Cursor's integration is convenient.

### Platform and Lock-In

Conductor is macOS only. Cursor runs on macOS, Windows, and Linux but centers on its own models and editor. Neither is agent-agnostic in the way a dedicated orchestrator is: Conductor supports three agents, and Cursor is primarily its own.

## Frequently Asked Questions

### Can Conductor run Cursor?

Yes. Conductor runs Claude Code, Codex, and Cursor agents in parallel, each in its own Git worktree. Existing users can use Cursor's agent inside Conductor's orchestration flow until the Mac app winds down in early 2027.

### Do Conductor and Cursor both use Git worktrees?

Yes. Conductor uses a worktree per task, and Cursor 2.0 runs its parallel agents in local Git worktrees too. Paradev uses Git worktrees for new local branch-based workspaces.

### Which is better for parallel agents?

Conductor was purpose-built for it on macOS, but it is now closed to new users. Cursor builds it into the editor across platforms. For agent-agnostic parallel orchestration with remote hosts, Paradev is a strong alternative.

### Is Conductor or Cursor free?

Conductor no longer sells plans or takes new sign-ups. Existing free users cannot upgrade, and existing Pro users keep Pro features for free. Cursor has a free tier with paid plans from $20/month.
