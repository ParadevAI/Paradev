Claude Code is Anthropic's terminal coding agent. Amp is a multi-model agent that picks models for you by mode and runs work on cloud machines called orbs. Both run subagents, support MCP, plugins, and skills, and have a headless mode. The choice is between one lab's agent with the deepest set of parallel modes, and an agent that chooses models for you and comes with its own cloud and apps. Since October 10, 2026, you can even use a Claude plan inside Amp through its Claude Code mode, which runs on the Claude Agent SDK.

Facts were checked against Anthropic's and Amp's own docs on October 13, 2026, and Amp's facts again against its manual, pricing, and news pages on November 5, 2026.

## What Is Claude Code?

Anthropic's agent "reads your codebase, edits files, runs commands, and integrates with your development tools." It has the widest set of parallel modes of any agent, from subagents and `/batch` runs across worktrees to an agent view, cloud sessions, and Remote Control, with plugins, skills, and hooks. It runs Anthropic's models on a paid Claude plan or an API key.

## What Is Amp?

Amp is "a coding agent and development environment built for the frontier." You pick a mode on a dial from low to ultra, and Amp chooses the model. Subagents run automatically, orbs keep threads running on cloud machines after you close your laptop, and since October 2026 you can self-host orbs on your own infrastructure. Runners execute threads on your own machines and create Git worktrees. Work can start from Slack, a Linear issue you assign to Amp, GitHub or GitLab events, webhooks, or a schedule. Threads follow you across the terminal, web, macOS, iOS, and Android. Amp is free with your own compute and keys, and the Individual plan starts at $20 a month with orb minutes.

## Key Differences

### Models

Claude Code runs Anthropic's models in Anthropic's harness. Amp chooses among several vendors' models for each mode, which keeps you on what it considers best without picking yourself. You can tune the model behind each Amp mode, or pick its Claude Code mode to run on your Claude plan.

### Parallel Work and Cloud

Claude Code has more built-in parallel modes on your machine. Amp leans on its own infrastructure: orbs for cloud work, self-hosted orbs for your own infrastructure, and runners with worktrees for your machines.

### Price

Amp can be free if you bring your own compute and keys. Claude Code needs a Claude plan or API spend. If you already pay for Claude, you can use that plan in either.

## Which Should You Choose?

**Choose Claude Code if you:**

- Want the richest set of parallel modes and plugins
- Want Anthropic's models in Anthropic's own harness
- Want worktree isolation built into the agent

**Choose Amp if you:**

- Want the agent to choose the best model for each task
- Want cloud machines that keep working after you close your laptop, hosted by Amp or on your own infrastructure
- Want threads on the web, macOS, iOS, and Android as well as the terminal

## Frequently Asked Questions

### Can Amp use my Claude subscription?

Yes. Since October 10, 2026, Amp's Claude Code mode can use your Claude subscription. It runs on the Claude Agent SDK instead of Amp's own agent. Amp can also link a ChatGPT plan or use your own API keys.

### Is Amp free?

Amp is free if you bring your own compute and model keys. Claude Code has no free tier.

### Can I run Claude Code and Amp at the same time?

Yes. Give each its own Git worktree. In Paradev, each runs in its own workspace on the same repository.
