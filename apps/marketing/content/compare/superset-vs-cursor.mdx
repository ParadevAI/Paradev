Cursor started as an AI editor and is now a full agent platform: an Agents Window that runs agents locally, in the cloud, or over SSH, cloud agents on their own VMs, self-hosted machines, a coordinator agent in Projects, code hosting with Origin, and an iOS app that, since October 2026, can see and reply to the agents running on your computer. Superset solves a narrower problem in a different way: it is a local-first workspace that runs any CLI agent, including Cursor's own, in parallel Git worktrees on your machines and subscriptions, independent of any editor.

Facts were checked against Cursor's changelog, docs, and pricing page on October 13, 2026.

## What Is Superset?

Superset is a local-first desktop workspace for AI coding agents. It launches Claude Code, Codex, Cursor's agent, Antigravity CLI, GitHub Copilot, Amp, OpenCode, Droid, Muse Code, and any other CLI agent inside isolated Git worktrees with persistent terminal sessions, on your own subscriptions and keys, and never proxies model calls. Around that core it adds a Changes pane that commits, pushes, and opens PRs, a Pull Requests view with CI checks and line comments you can send to agents, a chat panel, an in-app browser with port detection and Design Mode, and an MCP server so agents and tools can create workspaces and launch agents. Remote Access adds a macOS or Linux machine as a host so workspaces keep running when your laptop sleeps, cloud workspaces run in the cloud without your own computer connected, and scheduled automations, a CLI, a TypeScript SDK, and a Slack bot cover unattended work. The [iPhone and iPad app](/mobile) lets you check on sessions and review diffs away from your desk. You can open any workspace in VS Code, Cursor, JetBrains, Zed, or Xcode. ## What Is Cursor?

Cursor is an AI editor that has grown into an agent platform. The Agents Window manages agents across many repositories, running locally, in the cloud, or over SSH, and gives local agents their own worktrees; in the editor, `/worktree`, `/best-of-n`, and `/multitask` cover parallel work. Cloud agents each get their own VM, start from prepared snapshots, and can subscribe to PRs, Slack, and schedules. Since September 2026, self-hosted machines let agents run on your own laptop, a VM, or worker pools on several cloud providers, and Projects, in beta, has a coordinator agent that plans work and hands it to many agents in parallel. Cursor also hosts code with Origin, reviews PRs with Bugbot, and since October 13 has an app marketplace. On October 6, 2026, Cursor added remote control for local agents: pair the iOS app with your desktop to see and reply to agents running on your computer, which must stay on. The CLI, `agent`, runs Cursor's agent in a terminal and lets other editors drive it over ACP. Cursor runs its own agent; its docs do not describe running Claude Code or Codex.

## Key Differences

### Any Agent vs Cursor's Agent

Cursor's parallelism runs Cursor's agent, with your choice of model. Superset runs agents from every vendor in real terminals, so Claude Code, Codex, and Cursor's own agent can work on the same repository side by side, and you can continue a session with a different agent. If you like Cursor's agent, you can run it in Superset too.

### Who Pays for the Models

Superset never proxies model calls: each agent runs on your own subscription or key. Cursor bundles usage into its plans, bills third-party models at API list price, and refreshes usage weekly.

### Remote Agents and Mobile

Both now let you check on agents running on your own machine from a phone. Cursor's iOS app pairs with one desktop and shows its local agents, alongside its cloud agents. Superset's iPhone and iPad app connects to any macOS or Linux host you add through Remote Access and to cloud workspaces, with terminals and diff review for any agent running there.

### Cloud Infrastructure

Cursor offers managed cloud agents on their own VMs, started from prepared snapshots, and worker pools on several clouds. Superset has cloud workspaces that run in the cloud and open from desktop, iPhone, and iPad, and it also runs agents on machines you own through Remote Access.

### Editor-Centered vs Editor-Independent

Cursor's editor is the center of its product, and some CLI features work only in the editor. Superset works alongside whichever editor you use, and many Superset users run it next to Cursor.

## Pricing

Superset offers a free tier and Pro at $20 per user per month, or $15 per user per month billed yearly, with an enterprise tier on custom billing. Model costs are on your own agent subscriptions. Cursor's pricing page lists Free, Plus at $8 a month, Premium at $30, Super at $100, Ultra at $200, Teams from $30 per user, and Enterprise on custom terms. Cloud agents, automations, Origin, and Bugbot start at Premium, and third-party models are billed at API list price on every tier. Prices as of October 2026.

## Which Should You Choose?

**Choose Superset if you:**

- Run CLI agents from several vendors and want them side by side
- Want model costs on your own subscriptions, with no proxy
- Want agents on machines you own, reachable from an iPhone or iPad app
- Use JetBrains, Xcode, Neovim, Zed, or Cursor itself, and want orchestration that is not tied to one editor

**Choose Cursor if you:**

- Want one product for AI editing, local and cloud agents, and code review
- Want cloud agents on prepared VM snapshots and worker pools across several clouds
- Want a coordinator built into a Projects view that plans work for Cursor's own agents
- Prefer Cursor's agent and editor as the center of your workflow

The two also work together: use Cursor as your editor, and Superset to run Claude Code, Codex, and Cursor's agent in parallel worktrees around it.

## Frequently Asked Questions

### Is Superset a Cursor replacement?

Not as an editor. Superset does not offer Cursor-style inline completions. It is the workspace for running and reviewing many agents, and it opens any workspace in Cursor when you want to edit.

### Does Cursor support parallel agents?

Yes. The Agents Window runs agents locally, in the cloud, or over SSH, with worktrees for local agents, and Projects has a coordinator agent in beta. Cursor's parallelism runs its own agent; Superset runs any CLI agent in worktrees on your machines.

### Can I control local Cursor agents from my phone?

Yes, since October 6, 2026: pair Cursor's iOS app with your desktop to see and reply to its local agents. Superset's iPhone and iPad app does the same for any agent running on any macOS or Linux host you add.

### Can I run Cursor's agent in Superset?

Yes. Cursor's agent is a built-in agent in Superset, and runs in its own worktree next to Claude Code, Codex, and any other CLI agent.
