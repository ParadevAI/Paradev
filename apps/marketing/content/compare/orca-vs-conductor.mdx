On November 4, 2026, Conductor announced that it is joining Meta. It takes no new sign-ups, and the app can no longer be downloaded. Conductor Cloud becomes read-only on November 13, 2026, and shuts down on November 20, 2026. The local Mac app gets new models and critical bug fixes until early 2027, then winds down. See [Conductor's announcement](https://www.conductor.build/announcement). Existing Conductor users can follow [Migrate from Conductor](https://docs.paradev.com/migrate-from-conductor) or [Migrate from Conductor Cloud](https://docs.paradev.com/migrate-from-conductor-cloud) to move to Paradev.

This page shows how Orca and Conductor compared. They solve the same problem from opposite ends. Both run several AI coding agents at once, each in its own Git worktree, with review and merge in the app. Orca is free, MIT-licensed, cross-platform, and supports a long list of agents. Conductor is a polished, proprietary Mac app for four agents, which had managed cloud workspaces, Routines, and an iOS app on its paid plans.

For a three-way comparison that includes Paradev, see [Paradev vs Orca vs Conductor](/compare/superset-vs-orca-vs-conductor).

Conductor facts were checked against its own site, docs, changelog, and pricing on October 13, 2026, and its status against its announcement on November 4, 2026. Orca facts were rechecked against its site, docs, and GitHub releases on November 5, 2026.

## What Is Orca?

Orca calls itself "the agent development environment." It is an MIT-licensed desktop app for macOS, Windows, and Linux that runs agents in parallel worktrees, with terminals or a Chat UI (out of experimental since November 2, 2026), an embedded browser with Design Mode, inline diff comments sent back to the agent, and GitHub and Linear PRs and issues in the app. It names more than 25 supported agents plus any other CLI agent, tracks usage and resets for about a dozen agents and plans, including Claude Code, Codex, Gemini, Kimi Code, and MiniMax, with an account switcher for Claude and Codex, and has iOS and Android companion apps in beta. It also has plugins, a Jira drawer, and computer use for desktop apps. For remote work it supports SSH worktrees, Remote Orca Servers in beta, and a headless `orca serve`. Its CLI covers worktrees, browser automation, and scheduled automations; multi-agent orchestration is an experimental setting.

## What Is Conductor?

Conductor describes itself as a way to "run parallel coding agents on your Mac." It runs Claude Code, Codex, Cursor, and OpenCode, each task in its own workspace and branch, and takes a change through diff, checks, pull request, merge, and archive. Conductor Cloud, launched in July 2026, ran workspaces in managed Linux sandboxes on Pro and above. Routines, added in September, ran agents on a schedule or from a GitHub action in the cloud. Conductor also has an API and an MCP server, and on October 2, 2026, it added an iOS app for chatting with agents and merging PRs, which worked with cloud workspaces.

Conductor is now joining Meta and is closed to new users. Conductor Cloud shuts down on November 20, 2026, and Conductor then begins to delete cloud data. The local Mac app winds down after early 2027. Conductor says its team will ship something new early next year.

## Orca vs Conductor: Key Differences

### Platform and License

Orca runs on macOS, Windows, and Linux and is open source. Conductor is a Mac app and proprietary, and it is now closed to new users.

### Agent Coverage

Orca supports far more agents out of the box and runs any other CLI agent. Conductor supports four. If you switch agents often, Orca is the broader option.

### Cloud and Remote Work

Conductor's cloud was managed: Conductor ran the sandboxes for you (on Vercel), on paid plans, with collaboration and Routines built on top. It shuts down on November 20, 2026. Orca's remote options run on machines you control: SSH worktrees, Remote Orca Servers, and experimental cloud VMs on your own provider. Orca does not sell hosting.

### Mobile

Orca's iOS and Android apps control your desktop and are in beta. Conductor's iOS app, released in October, worked with its cloud workspaces, which shut down on November 20, 2026.

### Pricing

Orca is free. Conductor's plans are no longer on sale. Existing free users cannot upgrade, existing Pro users keep Pro features at no cost, and active Conductor Cloud subscribers get refunds.

## Where Paradev Fits

[Paradev](/) runs the same worktree-per-task model with any CLI agent, on your own subscriptions, on your machines or in cloud workspaces. Against both, its main differences are what can drive it from outside, through an MCP server, a TypeScript SDK, a CLI, and a Slack bot, and a review loop that commits, pushes, opens PRs, shows CI checks, and sends line comments back to agents. Besides your own machines, it can run on a Linux server in your own cloud account with [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud) or in [cloud workspaces](https://docs.paradev.com/cloud-workspaces) (beta). Its iPhone and iPad app connects to cloud workspaces, BYOC servers, and macOS or Linux hosts you own. Paradev is open source under the MIT License and runs on macOS with an experimental Linux build; Windows is not yet available. See [Paradev vs Orca](/compare/superset-vs-orca) and [Paradev vs Conductor](/compare/superset-vs-conductor).

## Frequently Asked Questions

### Is Conductor shutting down?

Conductor is joining Meta. It takes no new sign-ups, and the app can no longer be downloaded. Conductor Cloud becomes read-only on November 13, 2026, and shuts down on November 20, 2026. The local Mac app gets new models and critical bug fixes until early 2027, then winds down.

### Do Orca and Conductor both use Git worktrees?

Yes. Each gives every task its own Git worktree or branch, so agents in separate workspaces do not edit the same files. Paradev uses the same model.

### Does Conductor run on Windows or Linux?

No. Conductor is a Mac app, and it is now closed to new users. Its cloud workspaces ran in Linux sandboxes until Conductor Cloud shuts down on November 20, 2026. Orca runs on macOS, Windows, and Linux. Paradev supports macOS and an experimental Linux AppImage.

### Which supports the most coding agents?

Orca names more than 25 agents and runs any other CLI agent. Conductor supports Claude Code, Codex, Cursor, and OpenCode. Paradev runs any CLI agent, with built-in presets for more than 20.

### Is Orca free?

Yes. Orca is MIT-licensed and free. Conductor's plans are no longer on sale.

### Can I use my existing Claude or Codex subscription?

Yes. Orca and Paradev run the agent CLIs under your own login in local workspaces, so you keep your existing plan. The Conductor Mac app does the same for existing users.
