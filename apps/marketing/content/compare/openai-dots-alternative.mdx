OpenAI's dots, announced on September 29, 2026, are always-on ChatGPT agents powered by GPT-6 Astra. Each dot has its own cloud computer and browser, works across your apps, runs scheduled tasks, and hands coding work to Codex. The first dot is included in ChatGPT Pro and Business Premium plans. You might want an alternative if you want agents running on your own machines, a choice of agents beyond OpenAI's, or a workspace built around reviewing code rather than a general assistant. Here are the best alternatives in 2026.

## Why Look for an OpenAI dots Alternative?

A dot is a general agent first. It lives on OpenAI's cloud computer, uses GPT-6 Astra, and does coding by starting Codex tasks. It reaches your own machine only if you connect one personal computer, which is off by default. That suits people who want an assistant across their apps. It suits developers less well if they want to run Claude Code, Gemini CLI, and Codex side by side, keep agents on hardware they control, or review each diff in a workspace built for code. dots are also new: rollout started on September 29, 2026, the enterprise version is in beta, and extra dots are not for sale yet.

## The Best Alternatives

### 1. Superset

Superset is a local-first desktop workspace that runs any CLI coding agent in parallel Git worktrees: Codex, Claude Code, Cursor Agent, OpenCode, Gemini CLI, Copilot, Grok Build, Muse Code, Amp, and more, on your own subscriptions and keys. It covers the always-on part with Remote Access, which adds a macOS or Linux machine as a host so workspaces keep running when your laptop sleeps, and with scheduled automations, a CLI, a TypeScript SDK, an MCP server, and a Slack bot. The Changes pane commits, pushes, and opens PRs, the Pull Requests view shows CI checks and sends line comments back to agents, and the [iPhone and iPad app](/mobile) lets you review diffs away from your desk. Superset runs Codex with GPT-6 Astra in its model picker, so you keep OpenAI's model on your own hardware.

**Best for:** developers and teams who want unattended coding agents, from any vendor, on machines they control.

For the direct comparison, see [Superset vs OpenAI dots](/compare/superset-vs-openai-dots).

### 2. Codex

Codex is the coding agent a dot hands its work to, and you can use it directly. It ships as a CLI, IDE extensions, a coding surface in the ChatGPT desktop app with worktree mode, and a cloud agent that runs tasks in OpenAI-managed environments. If you want OpenAI's models on code without an always-on assistant in between, Codex is the shorter path.

**Best for:** developers who want OpenAI's coding agent and do not need a general assistant.

See [Superset vs Codex App](/compare/superset-vs-codex-app).

### 3. Grok Bot

xAI's Grok Bot is the closest product in shape: always-on AI teammates on a persistent cloud computer that work inside apps the way a person would. It runs on Cursor-hosted cloud computers, with Cursor choosing the model, and is bundled with eligible SuperGrok and Cursor plans. Like dots, it is aimed at general work more than at code review.

**Best for:** teams that want always-on teammates for sales, recruiting, and operations.

See [Superset vs Grok Bot](/compare/superset-vs-grok-bot).

### 4. Devin

Devin is Cognition's autonomous AI software engineer. Each session runs in its own cloud VM with a browser, editor, terminal, and planner, and you assign work in chat, Slack, or from Linear. Devin opens pull requests and reviews them before a human does, with paid tiers from $20 per month.

**Best for:** teams that want to delegate whole tickets to a cloud engineer.

See [Superset vs Devin](/compare/superset-vs-devin).

### 5. Paseo

Paseo is an Apache-2.0 "control plane for coding agents": a self-hosted daemon that runs Claude Code, Codex, OpenCode, and more in worktrees, with native desktop, iOS, Android, and web clients. Agents run on your own hardware and you drive them from your phone. It is free and needs no account.

**Best for:** solo developers who want a self-hosted, mobile-first setup.

See [Superset vs Paseo](/compare/superset-vs-paseo).

## How To Choose

- For coding agents from any vendor, on your own machines, with review built in: **Superset**.
- For OpenAI's coding agent without an assistant layer: **Codex**.
- For an always-on agent across your apps on a different vendor's stack: **Grok Bot**.
- For delegating whole tickets to a cloud engineer: **Devin**.
- For a free, self-hosted daemon you drive from your phone: **Paseo**.

## Frequently Asked Questions

### What is the best alternative to OpenAI dots for coding?

For coding work on your own machines, Superset. It runs Codex, Claude Code, and any other CLI agent in parallel Git worktrees, keeps workspaces running on a remote host, and puts diffs, PRs, and CI checks in one place.

### Can I run Codex without dots?

Yes. Codex is a separate product with a CLI, IDE extensions, a ChatGPT desktop app surface, and a cloud agent. Superset also runs the Codex CLI as a built-in agent, with GPT-6 Astra in its model picker.

### Are dots free?

The first dot is included in ChatGPT Pro and Business Premium plans at no extra cost, with an allowance for deeper work. Codex tasks a dot starts count toward your plan's limits. Superset has a free tier and Pro at $20 per user per month.

### Do dots run on my computer?

Each dot works on its own OpenAI cloud computer. You can connect one personal computer so a dot can continue local Codex tasks there; that is off by default.
