Conductor is joining Meta and is winding down. Since November 4, 2026, it takes no new sign-ups and the app can no longer be downloaded. This page shows how Conductor and Crystal compared, and what existing Conductor users can do.

Conductor and Crystal were close competitors: both are desktop apps that run Claude Code and Codex in parallel Git worktrees, with in-app diff review and merge. The main differences are platform, licensing, and project direction. Conductor is a proprietary macOS app; Crystal is open source and cross-platform, and is now continuing under the name Nimbalyst. Neither is agent-agnostic, which is where a broader workspace like [Paradev](/compare/superset-vs-conductor) comes in.

This page compares all three.

## What Is Conductor?

Conductor is a native macOS app from Melty Labs for running Claude Code, Codex, and Cursor agents in parallel, each in an isolated Git worktree, with a review-and-merge and pull-request flow. It is Mac only, proprietary, and reuses your existing agent subscriptions.

Conductor is joining Meta, announced on November 4, 2026. It no longer takes new sign-ups or sells plans, and existing Pro users keep Pro features for free. The local Mac app gets new models and critical bug fixes until early 2027, then winds down. Conductor Cloud goes read-only on November 13, 2026 and shuts down on November 20, 2026. If you use Conductor today, see [Migrate from Conductor](https://docs.paradev.com/migrate-from-conductor) for the local Mac app and [Migrate from Conductor Cloud](https://docs.paradev.com/migrate-from-conductor-cloud) for cloud workspaces.

## What Is Crystal?

Crystal is an open-source Electron desktop app for running Claude Code and Codex in parallel Git worktrees, with per-iteration commits, in-app diff review, and integrated Git operations like rebase, squash, and merge. It is MIT licensed and cross-platform. Its maintainers have renamed the project and now direct active development to Nimbalyst, so treat Crystal as the legacy name for what is now Nimbalyst.

## Conductor vs Crystal: Key Differences

### Platform and License

Conductor is macOS only and proprietary. Crystal is open source (MIT) and runs on macOS, Windows, and Linux. If you need Windows or Linux, or want open-source code, Crystal (Nimbalyst) is the fit. Conductor was a polished native Mac app, but it is now closed to new users.

### Agents

Conductor runs Claude Code, Codex, and Cursor. Crystal runs Claude Code and Codex. Both are focused on the popular agents rather than being agent-agnostic.

### Project Direction

Conductor is joining Meta. Its Mac app gets new models and critical bug fixes until early 2027, then winds down. Crystal has been renamed and its active development moved to Nimbalyst, so evaluate Nimbalyst's current state rather than the legacy Crystal repo.

## Where Paradev Fits

Both Conductor and Crystal are focused on a small set of agents. If you want the same worktree-per-task model but agent-agnostic on macOS and experimental Linux, and extended with remote hosts, [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud), and [cloud workspaces](/cloud) in beta, Paradev is the broader option. It runs Claude Code, Codex, OpenCode, Cursor, Gemini, Mistral Vibe, and custom agents, with review, an in-app browser, and MCP built in. A chat interface shows Claude Code, Codex, OpenCode, and Pi sessions as a chat. Like Crystal, Paradev is open source under the MIT License. See [Paradev vs Conductor](/compare/superset-vs-conductor) and [Paradev vs Crystal](/compare/superset-vs-crystal).

## Frequently Asked Questions

### Do Conductor and Crystal both use Git worktrees?

Yes. Both give each agent session its own Git worktree and branch. Paradev uses worktrees for new local branch-based workspaces with support for CLI agents.

### Is Crystal still maintained?

Crystal has been renamed and its maintainers now direct active development to Nimbalyst. Evaluate Nimbalyst for current development.

### Is Conductor still maintained?

Conductor is joining Meta and is closed to new users. The local Mac app gets new models and critical bug fixes until early 2027, then winds down. Conductor Cloud shuts down on November 20, 2026.

### Which runs on Windows and Linux?

Crystal (Nimbalyst) is cross-platform. Conductor is macOS only. Paradev supports macOS and experimental Linux; Windows is not available.
