To run and check on coding agents from your phone, Superset's [iPhone and iPad app](/mobile) shows every agent you run in Superset (Claude Code, Codex, and any other CLI agent) on every machine you add, in one app. Vendor apps cover their own agent: Claude Code has Remote Control in the Claude app, and Codex is in the ChatGPT app.

These are not either/or. Superset runs the real `claude` CLI in a real terminal, so Claude Code's Remote Control still works for a session you start in Superset. Use the vendor app for one agent and its push notifications, Superset for the cross-agent, multi-machine view, or both on the same session.

The apps differ in one important way: whether your phone talks to **agents on your own machine** or to **agents in the vendor's cloud**, and whether it works with **one vendor's agent** or **any agent**. Facts were checked against each vendor's own docs and changelog on October 13, 2026, and Superset's Remote Control support was retested on October 14, 2026.

## The Options

### Superset

Superset's [iPhone and iPad app](/mobile) connects to any machine you add as a host through Remote Access, and shows the terminals and diffs of every agent running there: Claude Code, Codex, Cursor's agent, OpenCode, Antigravity CLI, and any other CLI agent. You can answer prompts, send follow-ups, and review diffs. It needs iOS 26 or iPadOS 26 or later, a Pro plan, and a host that stays awake and online. Because agents run on your own machines, they use your own subscriptions and your real environment.

**Best for:** running several different agents on your own machines and checking on all of them from one app.

### Codex in the ChatGPT app

Since OpenAI's DevDay on September 29, 2026, the ChatGPT iOS app can pair with a Mac or Windows computer running the ChatGPT desktop app. From your phone you can start Codex tasks there or in the cloud, steer them, approve actions, and review diffs and test results. Android phones can also control a host. The computer must stay awake.

**Best for:** Codex users who want their phone to drive Codex on their computer.

### Cursor

Since October 6, 2026, Cursor's iOS app can pair with your desktop to see and reply to the agents running on your computer, which must stay on. For Cursor's cloud agents, the app has an inbox and full PR review on iPhone and iPad.

**Best for:** Cursor users, for both local and cloud agents.

### Claude Code

Claude Code has Remote Control for sessions on your computer, and cloud sessions that run in Anthropic's environment. Remote Control also works for Claude Code sessions in Superset: type `/remote-control` in the workspace's terminal. It needs a claude.ai login on a Pro, Max, Team, or Enterprise plan, not an API key. See Anthropic's [Remote Control docs](https://code.claude.com/docs/en/remote-control).

**Best for:** Claude Code users who want Anthropic's own tools end to end.

### GitHub Copilot

You can steer Copilot CLI sessions from GitHub.com or GitHub Mobile, and hand work to Copilot's cloud agent with `/delegate`.

**Best for:** teams that work in GitHub.

### Amp

Amp's threads follow you across its terminal UI, web, and iOS and macOS apps, and its "orbs" are cloud machines that keep working after you close your laptop.

**Best for:** Amp users who want managed cloud machines.

### Orca, Paseo, and T3 Code

These agent workspaces all have iOS and Android apps that connect to agents on your own machines. Orca is a free, MIT-licensed environment; Paseo is a self-hosted, Apache-2.0 daemon; T3 Code is an MIT-licensed control surface with a web app as well.

See [Superset vs Orca](/compare/superset-vs-orca), [Superset vs Paseo](/compare/superset-vs-paseo), and [Superset vs T3 Code](/compare/superset-vs-t3-code).

## How To Choose

- **One vendor's agent:** use that vendor's app. Codex users have the ChatGPT app, Cursor users have Cursor's, and so on. If you run Claude Code in Superset, Remote Control still works for that session.
- **Several agents on your own machines:** use a workspace with a mobile app, such as Superset, so one app covers Claude Code, Codex, and the rest.
- **Android:** Orca, Paseo, and T3 Code have Android apps, and Android phones can control a Codex host. Superset's Android app is on the [waitlist](/mobile#android).

## Keep Your Agents Reachable

Every option that runs agents on your own machine needs that machine to stay awake and online. For an always-on setup, run agents on a dedicated machine, such as a Mac mini or a Linux server. In Superset, run the host service from the standalone CLI so it stays reachable while the desktop app is closed; see [Keep Agents Running](https://docs.superset.sh/keep-agents-running).

## Frequently Asked Questions

### Can I run Claude Code from my phone?

Yes. Claude Code has Remote Control for sessions on your computer. Superset's iPhone and iPad app also shows Claude Code sessions running on any host you add, next to your other agents.

### Can I use Claude Code Remote Control and Superset's mobile app on the same session?

Yes. Start Claude Code in a Superset workspace and type `/remote-control`. The Claude app follows that session, and Superset's iPhone app shows the same terminal next to your other agents. Keep the terminal open; closing its last pane ends the session.

### Can I control Codex on my computer from my phone?

Yes. Since September 29, 2026, the ChatGPT iOS app can pair with a Mac or Windows computer running the ChatGPT desktop app and start, steer, and review Codex tasks there.

### Is there one app for all my coding agents?

Workspaces that run any agent, such as Superset, give you one mobile app for all of them. Vendor apps cover only their own agent.

### Does the agent run on my phone?

No. In every option here, the agent runs on a computer or in the cloud, and your phone is a remote control and review screen.
