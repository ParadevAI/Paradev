Windsurf is now Devin Desktop. After Cognition acquired Windsurf, it shipped the rename as an update, retired the Cascade agent in favor of Devin Local, and made an Agent Command Center the default view. If you liked Windsurf as an editor and do not want to move into Cognition's agent product, or you want to run Claude Code, Codex, and other CLI agents side by side, you have good options. Superset runs any CLI agent in its own Git worktree, with diff review, an in-app browser, and automations, beside whichever editor you choose.

**Our recommendation: choose Superset if you want to run several agents in parallel and keep the editor you like.** The alternatives below cover other preferences, including AI editors that replace Windsurf directly.

[Download Superset](/download) to try a small task, or read [Superset vs Windsurf](/compare/superset-vs-windsurf) for the direct comparison. This guide is published by Superset; recommendations describe workflow fit rather than benchmark results.

## Why Look for a Windsurf Alternative?

- **Cascade is gone.** Devin Local replaced the Cascade agent, so the agent you learned is not the agent you get.
- **A different product.** Devin Desktop puts an agent command center first. If you wanted an editor, that is a change in direction.
- **Agent choice.** You want Claude Code, Codex, or another CLI agent as the main agent, not a guest.
- **Local isolation.** You want each agent in its own local worktree, so several can work on one repository at once.
- **Vendor risk.** You prefer not to depend on one company's editor and agent together.

## The Best Alternatives

### Superset

Superset runs any CLI agent, such as Claude Code, Codex, OpenCode, Cursor's agent, Copilot CLI, Gemini CLI, and Amp, each in its own Git worktree with persistent terminal sessions. It adds a Changes pane that commits, pushes, and opens PRs, a pull request view with checks and review threads, an in-app browser with Design Mode, and a Workspaces page that shows which agents need you. Open any workspace in VS Code, Cursor, JetBrains, Zed, or Xcode when you want to edit by hand. Workspaces run on your machine, on hosts you add through Remote Access, or in cloud workspaces, and the [iPhone and iPad app](/mobile) reaches all of them.

For the direct comparison, see [Superset vs Windsurf](/compare/superset-vs-windsurf).

### Cursor

Cursor is the most direct replacement for Windsurf as an AI editor. It now includes an Agents Window that runs agents locally, in the cloud, or over SSH, cloud agents on their own VMs, and an iOS app that can reply to agents on your computer. Plans start free.

See [Superset vs Cursor](/compare/superset-vs-cursor).

### Zed

Zed is a fast, open-source editor written in Rust. Its Parallel Agents feature runs threads with Zed's own agent, external agents over the Agent Client Protocol (Claude, Codex, Gemini CLI, OpenCode, and more), or any CLI agent in a terminal thread, with optional worktree isolation per thread. The Personal plan is free with your own keys or external agents.

See [Superset vs Zed](/compare/superset-vs-zed).

### VS Code + GitHub Copilot

Windsurf started as a VS Code fork, so going back to VS Code is a short move. Copilot adds agent mode in the editor, a cloud coding agent that opens PRs, and MCP support. Plans start free, with Pro at $10/month, Pro+ at $39/month, and Max at $100/month.

See [Superset vs GitHub Copilot](/compare/superset-vs-github-copilot).

### JetBrains Air

JetBrains Air runs Codex, Gemini, Copilot, Claude Agent, Junie, and ACP Registry agents, each in a worktree or container, as a desktop app and inside JetBrains IDEs. Choose it if you work in IntelliJ, PyCharm, or WebStorm.

See [Superset vs JetBrains Air](/compare/superset-vs-jetbrains-air).

### Claude Code desktop

Anthropic's desktop app runs Claude Code sessions in parallel, with a worktree option, a diff view, a browser pane, SSH sessions, and cloud sessions. Choose it if Claude is the only agent you need.

See [Superset vs Claude Code App](/compare/superset-vs-claude-code-app).

## How To Choose

- To run several CLI agents in parallel beside any editor, choose **Superset**.
- For the closest AI-editor replacement, choose **Cursor**.
- For a fast open-source editor that hosts external agents, choose **Zed**.
- To go back to VS Code, choose **VS Code + GitHub Copilot**.
- If you live in JetBrains IDEs, choose **JetBrains Air**.
- If Claude is your only agent, choose **Claude Code desktop**.

## Frequently Asked Questions

### What happened to Windsurf?

Cognition acquired Windsurf and renamed it Devin Desktop. The update kept compatibility with Windsurf, retired the Cascade agent in favor of Devin Local, and made an Agent Command Center the default view.

### What is the best Windsurf alternative?

For an AI editor, Cursor is the closest replacement. For running several coding agents in parallel beside any editor, Superset is our recommendation.

### Is there an open-source Windsurf alternative?

Yes. Zed is open source. Superset is source-available under Elastic License 2.0.

### Can I use Superset with Cursor or VS Code?

Yes. Superset runs the agents and holds each task in its own worktree. Open any workspace in Cursor, VS Code, JetBrains, Zed, or Xcode to edit it.
