Muse Code is Meta's coding agent for the terminal and CI, built for the Muse Spark models. Superset is a local-first desktop workspace that runs Muse Code, Claude Code, Codex, and any other CLI agent in parallel, each in its own Git worktree, with review, pull requests, a browser, and automations around them. The two are not really rivals: Muse Code is an agent, and Superset is where you run and review agents. Muse Code has been a built-in agent in Superset since September 2026.

## What Is Superset?

Superset is a local-first desktop workspace for AI coding agents. It launches Muse Code, Claude Code, Codex, Cursor Agent, OpenCode, Gemini CLI, GitHub Copilot, Grok Build, Amp, and any other CLI agent inside isolated Git worktrees with persistent terminal sessions, on your own subscriptions and keys, and never proxies model calls. Around that core it adds a Changes pane that commits, pushes, and opens PRs, a Pull Requests view with CI checks and line comments you can send to agents, a chat panel, an in-app browser with port detection and Design Mode, and an MCP server so agents and tools can create workspaces and launch agents. Remote Access adds a macOS or Linux machine as a host, and scheduled automations, a CLI, a TypeScript SDK, and a Slack bot cover unattended work. Source-available under Elastic License 2.0 (ELv2).

## What Is Muse Code?

Meta describes Muse Code as "Meta's coding agent for the terminal and CI, built for Muse Spark." It launched in early beta on August 5, 2026 and came out of beta on August 31. It is a terminal UI, `muse`, with a headless mode, `muse exec`, for scripts and CI, and a session protocol with TypeScript and Python SDKs. Muse Code runs subagents by default, up to 8 agents per tree, and each subagent can get its own Muse-managed Git worktree. Workflows run teams of subagents in parallel or in stages. It supports MCP, hooks, and skills and plugins imported from Claude and Codex, and it can continue a local Claude Code or Codex session. Models are Muse Spark and, on higher plans, Muse Wonder. Subscriptions are sold as usage tiers that reset every 5 hours and weekly, and API access is billed per token; cheaper "Contributor" models and plans let Meta train on your data.

## Key Differences

### Workspace vs Agent

Muse Code is the agent that writes the code. Superset is the workspace around agents: it creates a worktree and branch per task, keeps terminal sessions alive, shows the diff, and takes the change through commit, push, and pull request. You can use Muse Code on its own in a terminal, or run it inside Superset to get that review loop.

### One Model Family vs Many

Muse Code is built for Meta's Muse models. Superset runs agents from every vendor side by side, so you can give one task to Muse Code, the next to Claude Code, and a third to Codex, then compare the diffs. If you are trying Muse Spark against the agents you already use, Superset is the easiest place to do it on the same repository.

### Subagents vs Parallel Workspaces

Both run work in parallel, at different levels. Muse Code splits one task across subagents and workflows inside a single session. Superset runs separate tasks, each in its own workspace, worktree, and terminal, and each with any agent. The two combine: a Muse Code session with its own subagents can be one of several workspaces in Superset.

### Terminal vs Review Surface

Muse Code is a terminal and CI tool. Superset adds the parts a terminal does not have: a Changes pane, a Pull Requests view with CI checks, line comments sent back to the agent, an in-app browser for your dev server, and an iPhone and iPad app to check on sessions away from your desk.

## Pricing

Superset offers a free tier and Pro at $20 per user per month, or $15 per user per month billed yearly. Superset does not charge for model usage; you bring your own agent subscriptions. Muse Code is sold as subscription tiers (Everyday, High, Power, and Maximum Usage) with prompt limits that reset every 5 hours and weekly, or through the API per token. As of October 2026, Muse Spark 1.3 costs $1.25 per million input tokens and $4.25 per million output tokens, and Muse Wonder 1.0 costs $4 and $20. Meta does not list subscription prices as text on its plans page.

## Which Should You Choose?

You do not have to choose. Muse Code runs inside Superset.

**Use Muse Code on its own if you:**

- Want one agent in a terminal, or in CI with `muse exec`
- Are happy splitting work across Muse Code's own subagents
- Only use Meta's models

**Run Muse Code in Superset if you:**

- Want several tasks running at once, each in its own worktree
- Use Muse Code next to Claude Code, Codex, or other agents
- Want diffs, PRs, CI checks, and a browser in one place
- Want sessions to keep running on a remote host, or to run on a schedule

**Verdict:** Muse Code is a capable agent with strong subagent and workflow support. Superset is the workspace that runs it alongside every other agent you use, with the review loop built in.

## Frequently Asked Questions

### Can I run Muse Code in Superset?

Yes. Muse Code is a built-in agent in Superset. Add it from **Settings → Agents → Add agent**. Superset resumes interrupted Muse Code sessions and shows its token history in the Usage tab.

### Is Muse Code free?

No. Muse Code needs a Muse subscription or API access. Subscriptions are usage tiers that reset every 5 hours and weekly, and the API is billed per token. Subscriptions default to Contributor mode, which gives more usage in exchange for letting Meta use your submitted content to train future models; you can turn it off in settings.

### Does Muse Code run agents in parallel?

Yes, inside one session. Muse Code runs up to 8 agents per tree by default, counting the root agent, and workflows that run teams of subagents in parallel or in stages. Superset runs separate tasks in parallel, each in its own workspace with any agent.

### Which platforms does Muse Code support?

Meta's site offers macOS and Windows installers, and its docs also describe Linux. Superset's desktop app runs on macOS, with an experimental Linux AppImage; Windows is not yet available.
