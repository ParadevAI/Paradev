Paradev, Orca, and Conductor all run several AI coding agents at once, each in its own Git worktree, with review and pull requests in the same app. They differ in which agents they run, where those agents run, and how a team works together around them. This comparison is for solo developers and engineering teams choosing one.

On November 4, 2026, Conductor announced that it is joining Meta. It takes no new sign-ups, and the app can no longer be downloaded. Conductor Cloud becomes read-only on November 13, 2026, and shuts down on November 20, 2026. The local Mac app gets new models and critical bug fixes until early 2027, then winds down. The Conductor column below shows how it compared before the wind-down. Existing Conductor users can follow [Migrate from Conductor](https://docs.paradev.com/migrate-from-conductor) or [Migrate from Conductor Cloud](https://docs.paradev.com/migrate-from-conductor-cloud).

Facts for Paradev and Orca were checked against each product's own site, docs, changelog, and pricing on November 5, 2026. Conductor's status was checked against its [announcement](https://www.conductor.build/announcement) on November 4, 2026. This page is published by Paradev.

## What Each One Is

### Paradev

Paradev is a desktop workspace for orchestrating CLI coding agents. Each task runs in its own workspace with a Git worktree and a persistent terminal, so you can run Claude Code, Codex, and any other agent side by side, on your own subscriptions; Paradev never proxies model calls. Terminals run in a background daemon, so agents keep running when you close or update the app. Remote Access adds macOS or Linux machines as shared hosts for your team. [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud) runs the host on a Linux server in your own cloud account, and [cloud workspaces](/cloud) (beta) run in a sandbox that Paradev manages. The [iPhone and iPad app](/mobile) reaches all of them away from your desk. Tasks sync with Linear and GitHub Issues, and a CLI, a TypeScript SDK, an MCP server, and a Slack bot let other tools and agents create workspaces and launch agents. Paradev works alongside your editor: open any workspace in VS Code, Cursor, JetBrains, Zed, or Xcode. It is open source under the MIT License.

### Orca

Orca is an MIT-licensed agent development environment for macOS, Windows, and Linux. It names more than 25 supported agents, lets you use each one in a terminal or a Chat UI (out of experimental since November 2, 2026), has an embedded browser with Design Mode, inline diff comments sent back to the agent, GitHub and Linear issues and PRs in the app, plugins, and usage tracking for about a dozen agents and plans, including Gemini, Kimi Code, and MiniMax, which Paradev does not track. It reaches other machines through SSH worktrees, Remote Orca Servers in beta, and a headless `orca serve`, and has iOS and Android companion apps in beta. It is free.

### Conductor

Conductor is a Mac app for running Claude Code, Codex, Cursor, and OpenCode in parallel, each task in its own workspace and branch, through to merge. Its paid plans added Conductor Cloud, managed Linux sandboxes with team collaboration, plus cloud Routines, an API and MCP server, and an iOS app that worked with cloud workspaces. Conductor is joining Meta and is closed to new users. Conductor Cloud shuts down on November 20, 2026, and the local Mac app winds down after early 2027.

## Key Differences

### Which Agents You Can Run

Paradev and Orca run any CLI agent; Orca names more than 25 and Paradev has built-in presets for more than 20. Both can show some agents as a chat: Paradev has a chat interface for Claude Code, Codex, OpenCode, and Pi, and Orca's Chat UI is out of experimental. Conductor supports four. If your team uses agents beyond Claude Code and Codex, or wants to compare several on the same task, Paradev or Orca fits.

### Where Agents Run, and Who Pays for It

Paradev and Orca run agents on machines you control: your laptop, or a shared host. Paradev can also run on a Linux server in your own cloud account, and it has cloud workspaces, which run in the cloud and are available from desktop, iPhone, and iPad without keeping your own computer connected. Conductor's cloud ran agents on its own sandboxes, on paid plans, until it shuts down on November 20, 2026. Paradev's shared hosts are part of the same desktop workspace, with access granted per member, so a team can keep long-running agents on a Mac mini or Linux server with its real environment.

### Review and Task Management

All three take work to a pull request. Paradev adds inline diff comments that go back to the agent, in both the Changes pane and a Pull Requests view with CI checks, and task intake from Linear, GitHub Issues, and Slack. Orca brings GitHub and Linear into the app with inline diff comments. Conductor covers diff, checks, PR, and merge.

### Driving It From Outside

Paradev exposes a CLI, a TypeScript SDK, and an MCP server, so scripts and agents can create workspaces and launch other agents; scheduled automations run on a host you choose. Conductor has an API and an MCP server; its cloud Routines end with Conductor Cloud. Orca has a CLI and scheduled automations, with orchestration still experimental.

### Platforms and License

Orca is the only one of the three on Windows today. Orca and Paradev are both open source under the MIT License; Paradev runs on macOS with an experimental Linux build. Conductor is a proprietary Mac app, now closed to new users.

### Mobile

Paradev and Orca have iPhone apps. Paradev's connects to hosts you own, Bring Your Own Cloud servers, and cloud workspaces, and shows any agent running there. Orca's controls your desktop and is in beta, with an Android APK. Conductor's iOS app worked with its cloud workspaces, which shut down on November 20, 2026.

## Frequently Asked Questions

### What is the difference between Paradev, Orca, and Conductor?

All three run AI coding agents in parallel Git worktrees. Paradev is a desktop workspace for any CLI agent, with shared hosts, task intake, and a CLI, SDK, and MCP server. Orca is a free, open-source, cross-platform environment with a wide agent list. Conductor is a Mac app for four agents that is joining Meta and is closed to new users; its managed cloud shuts down on November 20, 2026.

### Which works on Windows?

Orca. Paradev runs on macOS with an experimental Linux build, and Conductor is Mac only.

### Which is free?

Orca is free. Paradev has a free plan; Paradev Pro is {{price:pro}} per user per month. Conductor's plans are no longer on sale, and existing Conductor Pro users keep Pro features at no cost. Paradev Team ({{price:team}}) and Ultra ({{price:ultra}}) add cloud workspaces.

### Can I use my own Claude or Codex subscription?

Yes, in all three for local workspaces, though Conductor is closed to new users. Paradev never proxies model calls, so each agent runs on your own plan or key.

### Is Conductor shutting down?

Conductor is joining Meta. It takes no new sign-ups, and the app can no longer be downloaded. Conductor Cloud shuts down on November 20, 2026, and the local Mac app gets new models and critical bug fixes until early 2027, then winds down.

### Which fits a team?

It depends on where you want agents to run. For agents on machines you own or in cloud workspaces, with per-member access and enterprise controls, Paradev. For a free, cross-platform tool, Orca. Conductor is closed to new users, and its cloud shuts down on November 20, 2026.
