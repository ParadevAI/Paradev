Vibe Kanban is sunsetting. On April 10, 2026, bloop, the company behind it, [announced its shutdown](https://www.vibekanban.com/blog/shutdown). The project continues as community-maintained open source, local workspaces keep working, and the remote services (issues, comments, projects, and organisations) stayed up for 30 days and were then removed. If you ran Claude Code, Codex, or other agents in parallel worktrees from Vibe Kanban and want an actively developed home for that workflow, move to Paradev (formerly Superset): it runs the same agents in their own Git worktrees, with a board of tasks and workspaces, review, and remote and cloud workspaces.

**Our recommendation: move to Paradev if you want the same agents and worktrees with active development, a board, and review in one app.** If you want to stay fully open source, Orca and Emdash are the closest matches. If Vibe Kanban still works for you, you do not have to move today.

[Download Paradev](/download) and follow the migration steps below, or read [Paradev vs Vibe Kanban](/compare/superset-vs-vibe-kanban) for the direct comparison. This guide is published by Paradev; recommendations describe workflow fit rather than benchmark results.

## Is Vibe Kanban Shutting Down?

Yes, as a company product. These facts come from the [shutdown post](https://www.vibekanban.com/blog/shutdown), the [vibekanban.com](https://www.vibekanban.com) banner, and the [GitHub repository](https://github.com/BloopAI/vibe-kanban), checked on October 29, 2026:

- **Announced:** April 10, 2026. The site banner reads: "Vibe Kanban is sunsetting. The project will continue as open source and community maintained."
- **Removed:** remote services (kanban issues, comments, projects, and organisations) after 30 days. Vibe Kanban now runs as a fully local app.
- **Still works:** local workspaces, and `npx vibe-kanban` still installs it.
- **Still maintained by the community:** the repository is not archived, and commits still land (the most recent on October 28, 2026). The last tagged GitHub release is v0.1.44 from April 24, 2026.
- **Your data:** the shutdown post says the latest version includes a data export. In the repository, the export writes a ZIP with an `issues.csv` file and, optionally, attachments.

## Why Look for a Vibe Kanban Alternative?

The code is still Apache-2.0 and local workspaces still run. Common reasons to move anyway:

- **Maintenance.** Fixes for new agent versions now depend on community contributors, not a funded team.
- **Team features.** Shared issues, comments, projects, and organisations were remote services, and they are gone.
- **Reach.** You want to run agents on other machines or in the cloud and check on them from your phone.
- **Automation.** You want scheduled or event-triggered agent runs, or an API that lets agents start other agents.

## How To Move From Vibe Kanban to Paradev

Most of a Vibe Kanban setup carries over, because both tools run the same CLI agents in plain Git worktrees. Work in progress and new work take different paths: you continue unfinished work inside the worktree you import, and you start new work from a task in a new workspace.

1. **Export what you have.** Use the data export in the latest Vibe Kanban version, and keep the ZIP. Its `issues.csv` is your list of open work.
2. **Add your repository.** In Paradev, add the same local repository as a project.
3. **Import your worktrees.** Open the **Import** tab in the New Workspace modal, or right-click the project and choose **Import untracked worktrees**. Paradev lists the Git worktrees registered in the repository, including ones Vibe Kanban created, and turns each into a workspace on its existing branch, with its unfinished changes. See [Workspaces](https://docs.paradev.com/workspaces).
4. **Continue work in progress.** Open an imported workspace and start the agent you used before in that workspace: open a terminal there and run the agent, or run `superset agents create --workspace <workspace-id> --agent claude --prompt "..."`. The agent works on the same branch and files. See the [CLI reference](https://docs.paradev.com/cli/cli-reference#superset-agents-create).
5. **Start new work from your open issues.** Connect Linear, use GitHub issues from your repositories, or create Paradev tasks in the app or with `superset tasks create`. Then choose **Run in workspace** on a task and select an agent: Paradev creates a new workspace and worktree for each task, with the agent already working on the task as its prompt. **Run in workspace** does not reuse an imported worktree. See [Tasks](https://docs.paradev.com/tasks).
6. **Watch the board.** The Workspaces page has a board with Working, Needs attention, Needs review, and Merged columns.

### Which Vibe Kanban agents run in Paradev?

Every agent on [Vibe Kanban's supported list](https://github.com/BloopAI/vibe-kanban/blob/main/docs/supported-coding-agents.mdx) runs in Paradev. Claude Code, Codex, GitHub Copilot, Gemini CLI, Amp, Cursor Agent, OpenCode, and Droid are built-in agents. Claude Code Router and Qwen Code run as custom agents: add them in **Settings → Agents → Add agent → Custom agent…**. See [Supported Agents](https://docs.paradev.com/supported-agents).

## The Best Alternatives

### Paradev

Paradev runs any CLI agent, such as Claude Code, Codex, OpenCode, Cursor Agent, Copilot, Gemini CLI, and Amp, each in its own Git worktree with persistent terminal sessions. You keep a board: the Tasks view shows Linear and Paradev tasks as a list or a kanban board, GitHub issues as a list, and **Run in workspace** starts a workspace with the agent already working. Around the agents, Paradev adds a Changes pane that commits, pushes, and opens PRs, a pull request view with checks and review threads, and an in-app browser with Design Mode. Workspaces run on your machine, on hosts you add through Remote Access, or in cloud workspaces, and the [iPhone and iPad app](/mobile) reaches all of them (Pro). Worktrees separate each agent's working files; they do not sandbox processes or prevent merge conflicts.

For the direct comparison, see [Paradev vs Vibe Kanban](/compare/superset-vs-vibe-kanban).

### Orca

Orca is a free, MIT-licensed desktop agent development environment for macOS, Windows, and Linux. It runs agents in parallel worktrees with per-task browser tabs, Design Mode, SSH worktrees, scheduled automations, and beta iOS and Android apps. Choose it if you want to stay open source and cross-platform.

See [Paradev vs Orca](/compare/superset-vs-orca).

### Emdash

Emdash is an Apache-2.0 desktop app for macOS, Windows, and Linux that supports 34 CLI agents. It gives each task its own branch and worktree and pulls tasks from Linear, Jira, GitHub, Notion, and Asana, which makes it the closest open-source match for Vibe Kanban's issue-first planning.

See [Paradev vs Emdash](/compare/superset-vs-emdash).

### Conductor

Conductor is a Mac app that runs Claude Code, Codex, Cursor, and OpenCode in parallel workspaces. Its Pro plan at $50/month adds cloud workspaces, multiplayer, an API, and an iOS app. Choose it if your team wants shared agent conversations in a managed cloud.

See [Paradev vs Conductor](/compare/superset-vs-conductor).

### Claude Squad

Claude Squad manages multiple agents in separate worktrees inside tmux, driven from one terminal UI. It has no board, but if you only used Vibe Kanban to run parallel agents in worktrees, it does that with very little machinery.

See [Paradev vs Claude Squad](/compare/superset-vs-claude-squad).
