Sculptor, from the AI lab Imbue, is an MIT-licensed desktop app for running coding agents in parallel. Each workspace is an isolated worktree of your repository. It ships with Claude Code and Imbue's Pi harness, can manage other terminal agents, and bundles workflow skills. Imbue calls it an experimental research preview, and it runs on Apple Silicon Macs and Linux. If you want a workspace with broad agent support, remote and cloud workspaces, and a phone app, Superset is built for that loop.

**Our recommendation: choose Superset if you want parallel agents in worktrees with review, automations, and remote and cloud workspaces.** The alternatives below cover other preferences, including open-source desktop apps.

[Download Superset](/download) to try a small task, or read [Superset vs Sculptor](/compare/superset-vs-sculptor) for the direct comparison. This guide is published by Superset; recommendations describe workflow fit rather than benchmark results.

## Why Look for a Sculptor Alternative?

- **Stability.** Imbue describes Sculptor as an experimental research preview that may change quickly.
- **Platform.** Sculptor downloads cover Apple Silicon Macs and Linux. You need Intel Mac or Windows.
- **Agent breadth.** Sculptor's integrated support is for Claude Code and Pi. You want first-class support for Codex, OpenCode, and others.
- **Reach.** You want to run agents on other machines or in the cloud and check on them from your phone.

## The Best Alternatives

### Superset

Superset runs any CLI agent, such as Claude Code, Codex, OpenCode, Cursor's agent, Copilot CLI, Gemini CLI, and Amp, each in its own Git worktree with persistent terminal sessions. It adds a Changes pane that commits, pushes, and opens PRs, a pull request view with checks and review threads, an in-app browser with Design Mode, and a Workspaces page that shows which agents need you. Workspaces run on your machine, on hosts you add through Remote Access, or in cloud workspaces, and the [iPhone and iPad app](/mobile) reaches all of them. Pro adds remote access, the iPhone and iPad app, and scheduled automations, and a CLI, TypeScript SDK, and MCP server let agents start other agents.

For the direct comparison, see [Superset vs Sculptor](/compare/superset-vs-sculptor).

### Conductor

Conductor is a Mac app that runs Claude Code, Codex, Cursor, and OpenCode in parallel workspaces. Its Pro plan at $50/month adds cloud workspaces, multiplayer, an API, and an iOS app.

See [Superset vs Conductor](/compare/superset-vs-conductor).

### Orca

Orca is a free, MIT-licensed desktop agent development environment for macOS, Windows, and Linux. It runs agents in parallel worktrees with per-task browser tabs, Design Mode, SSH worktrees, scheduled automations, and beta mobile apps.

See [Superset vs Orca](/compare/superset-vs-orca).

### Emdash

Emdash is an Apache-2.0 desktop app for macOS, Windows, and Linux that supports 34 CLI agents. It gives each task its own branch and worktree and pulls tasks from Linear, Jira, GitHub, Notion, and Asana.

See [Superset vs Emdash](/compare/superset-vs-emdash).

### Nimbalyst

Nimbalyst, the successor to Crystal, is an MIT-licensed visual workspace for Claude Code, Codex, and OpenCode on macOS, Windows, and Linux, with iOS and Android companions.

See [Superset vs Nimbalyst](/compare/superset-vs-nimbalyst).

### Claude Code desktop

Anthropic's desktop app runs Claude Code sessions in parallel, with a worktree option, a diff view, a browser pane, SSH sessions, and cloud sessions. Choose it if Claude Code is the agent you use in Sculptor and you want Anthropic's own app.

See [Superset vs Claude Code App](/compare/superset-vs-claude-code-app).

## How To Choose

- For any CLI agent with review, automations, and remote and cloud workspaces, choose **Superset**.
- For a polished Mac app with team cloud workspaces, choose **Conductor**.
- For a free, open-source, cross-platform ADE with mobile apps, choose **Orca**.
- For open source with issue-tracker intake, choose **Emdash**.
- For an open-source visual workspace, choose **Nimbalyst**.
- If Claude Code is your only agent, choose **Claude Code desktop**.

## Frequently Asked Questions

### What is the best Sculptor alternative?

For any CLI agent in parallel worktrees, with review, automations, and remote and cloud workspaces, Superset is our recommendation. Orca is the strongest open-source alternative.

### Is Sculptor still maintained?

Yes. Imbue continues to develop Sculptor and describes it as an experimental research preview.

### Is there an open-source Sculptor alternative?

Yes. Orca (MIT), Nimbalyst (MIT), and Emdash (Apache-2.0) are open source. Sculptor itself is MIT. Superset is source-available under Elastic License 2.0.

### Does Sculptor run on Windows?

Sculptor offers downloads for Apple Silicon Macs and Linux. Orca, Emdash, and Nimbalyst run on Windows. Superset runs on macOS with experimental Linux support; Windows is not yet available.
