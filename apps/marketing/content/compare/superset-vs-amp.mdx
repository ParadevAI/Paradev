Amp started as a coding agent and is growing into a development environment. Its agent picks models for you by mode, its "orbs" are cloud machines that keep working after you close your laptop, and since October 2026 you can also run orbs on your own infrastructure. Its runners create Git worktrees, can be shared across a team, and include the Amp Mac app. Orbs can start from Slack, Linear, GitHub, GitLab, webhooks, and schedules. Paradev is a local-first workspace that runs any CLI agent, Amp included, in parallel Git worktrees, with pull requests, a browser, automations, remote hosts, and cloud workspaces. The difference: Amp is one vendor's agent with its own infrastructure; Paradev is the workspace around every agent you use.

Facts were checked against Amp's own manual, pricing, and news pages on November 5, 2026.

## What Is Paradev?

Paradev is a local-first desktop workspace for AI coding agents. It launches Claude Code, Codex, Amp, Antigravity CLI, Cursor's agent, OpenCode, GitHub Copilot, Droid, Muse Code, and any other CLI agent in separate Git worktrees and branches with persistent terminal sessions, on your own subscriptions and keys, and never proxies model calls. Around that core it adds a Changes pane that commits, pushes, and opens PRs, a Pull Requests view with CI checks and line comments you can send to agents, a [chat interface](https://docs.paradev.com/chat) for Claude Code, Codex, OpenCode, and Pi, an in-app browser with port detection and Design Mode, and an MCP server so agents and tools can create workspaces and launch agents. Remote Access adds a macOS or Linux machine as a host so workspaces keep running when your laptop sleeps, and [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud) runs the host on a Linux server in your own cloud account. Scheduled automations, a CLI, a TypeScript SDK, and a Slack bot cover unattended work. The [iPhone and iPad app](/mobile) lets you check on sessions and review diffs away from your desk. Open source under the MIT License, with an enterprise tier that adds SAML SSO, SCIM, audit logs, and a SOC 2 Type II report.

## What Is Amp?

Amp calls itself "a coding agent and development environment built for the frontier." Instead of a model picker, you choose a mode on a dial from low to ultra, and Amp picks the model. You can tune the model behind each mode, and since October 10, 2026 a Claude Code mode runs on your Claude plan. It runs subagents automatically, supports custom agents through plugins, and lets agents start other agents. Puck, its assistant, launches and coordinates agents, and you can reach it from other apps through MCP.

Orbs are cloud machines, one per thread, that keep working after you close your laptop. Since October 22, 2026 you can self-host orbs on your own infrastructure, such as Docker, Kubernetes, E2B, Modal, or Daytona, and since October 29 an orb can start a cloud Mac to build and test iOS and Mac apps. Orbs can start from a Slack mention, a Linear issue you assign to Amp, a new GitHub or GitLab issue or pull request, a webhook, or a schedule. Runners execute threads on machines you choose: they create Git worktrees, can be shared across a team, and the Amp Mac app can act as one. Threads follow you across the terminal UI, the web, and Amp's macOS, iPhone, iPad, and Android apps. Teams get shared threads, multiplayer, SAML/OIDC SSO, and service accounts that own threads for the whole team. Amp is free if you bring your own compute and model keys; the Individual plan starts at $20 a month with orb minutes included. Its home page lists CLI installs for macOS, Linux, WSL, and Windows. Amp is proprietary and says it keeps "no backward compatibility, no legacy features."

## Key Differences

### Any Agent vs Amp's Agent

Amp's environment runs Amp's agent. Paradev runs agents from every vendor in real terminals, so Amp, Claude Code, and Codex can work on the same repository in separate worktrees, and you can continue a session with a different agent. If you like Amp's agent, you can run it in Paradev next to the others.

### Who Picks the Model

Amp chooses the model for each mode, which is simple and keeps you on whatever it considers best. You can tune the model behind a mode or switch to its Claude Code mode. In Paradev, each agent uses its own models on your own plan, and you choose the agent for each task.

### Cloud and Your Machines

Both products now cover the same three places: their cloud, your cloud, and your own machines. Amp's orbs give you a cloud machine per thread, self-hosted orbs run that same model on your own infrastructure, and runners cover your own machines and can be shared across a team. Amp can also start a cloud Mac for iOS and Mac builds. Paradev has [cloud workspaces](/cloud) (beta), included with Team and Ultra, which run in the cloud and work from desktop, iPhone, and iPad without keeping your own computer connected. [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud) runs the Paradev host on a Linux server in your own cloud account, with no inbound ports, and Remote Access adds machines you own as hosts and keeps workspaces running when your laptop sleeps. In each Paradev option, every agent runs, not only one vendor's.

### Triggers and Team Work

Amp can start work from Slack, Linear, GitHub, GitLab, webhooks, and schedules, and its service accounts let a team share the threads that automations create. Paradev's automations run on schedules and on GitHub, Slack, Linear, and other events, with run history, and tasks sync with Linear and GitHub Issues. The difference is again the agent: Amp's triggers start Amp, and Paradev's automations can start any agent you choose.

### Review and Pull Requests

Paradev's Changes pane commits, pushes, and opens pull requests, and its Pull Requests view shows CI checks and sends line comments back to the agent. Amp shows diffs in the thread, and since October 2026 it follows up on the pull requests it opens: comments, reviews, and CI results come back to the same thread. Paradev also has a [chat interface](https://docs.paradev.com/chat) that shows a Claude Code, Codex, OpenCode, or Pi session as a transcript you can approve step by step.

### Platforms

Amp has macOS, iPhone, iPad, and Android apps and a web client, and its CLI runs on macOS, Linux, WSL, and Windows. Paradev has a macOS desktop app, an experimental Linux build, and an iPhone and iPad app; Android is on a [waitlist](/mobile#android), and Windows is not yet available. Neither has a native Windows desktop app.

## Which Should You Choose?

**Choose Paradev if you:**

- Use more than one coding agent, and want them side by side
- Want pull requests, CI checks, and line comments back to any agent in one place
- Want any agent on machines you own, on your own cloud server, or in cloud workspaces, with scheduled automations and a Slack bot
- Want an MIT-licensed workspace you can read, change, and self-host
- Need enterprise controls: SAML SSO, SCIM, audit logs, SOC 2 Type II

**Choose Amp if you:**

- Want the vendor to pick the best model for each task
- Want one cloud machine per thread, hosted by Amp or on your own infrastructure, and shared team runners from the agent vendor
- Want Amp to start work from Slack, Linear, GitHub, or GitLab
- Want the same threads in the terminal, on the web, and on macOS, iOS, and Android

**Verdict:** Amp is a strong agent with its own cloud, self-hosted orbs, and apps. Paradev is the workspace for teams that use several agents, Amp among them, and want review through to the pull request, on their own machines or in cloud workspaces.

## Frequently Asked Questions

### Can I run Amp in Paradev?

Yes. Amp is a built-in agent in Paradev. It runs in its own worktree next to Claude Code, Codex, and any other CLI agent.

### Is Amp free?

Amp is free if you bring your own compute and model keys, and self-hosted orbs are free for individuals and teams. The Individual plan starts at $20 per month with orb minutes. Paradev has a free tier, Pro at {{price:pro}} per user per month, and Team ({{price:team}}) and Ultra ({{price:ultra}}) plans with cloud workspaces.

### Does Amp use Git worktrees?

Yes. Since September 2026, Amp's runners create Git worktrees for their threads. Paradev gives each new local branch-based workspace its own worktree and terminal.

### Does Amp run on Windows?

Amp's home page lists CLI installs for WSL and Windows. Its desktop app is for macOS. Paradev's desktop app runs on macOS, with an experimental Linux build.

### Can Amp run in my own cloud?

Yes. Since October 22, 2026, Amp supports self-hosted orbs on your own infrastructure. Paradev's [Bring Your Own Cloud](https://docs.paradev.com/bring-your-own-cloud) runs the Paradev host on a Linux server in your own cloud account, and every agent you use runs there.
