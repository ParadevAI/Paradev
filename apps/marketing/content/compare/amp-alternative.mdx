Amp is a coding agent that picks the model for you by mode, from fast to "ultra." It runs work on "orbs," cloud machines that keep going after you close your laptop, and on runners that create Git worktrees, with threads that follow you across the terminal, the web, and its iOS and macOS apps. It is free with your own compute and keys, or $20 a month for the Individual plan. Amp is proprietary and says it keeps "no backward compatibility, no legacy features." Superset lets you keep Amp and run any of these alternatives beside it, each in its own Git worktree, so you can compare the diffs on your own code.

**Our recommendation: keep Amp, and use Superset to try the alternatives side by side on the same task.** The list below covers the major labs' agents and open-source options.

## Why Look for an Amp Alternative?

Amp is a strong choice if you want the vendor to pick the model. Common reasons to look further:

- **Model control.** You want to choose the model yourself on every task.
- **Stability.** Amp removes features without keeping backward compatibility.
- **Open source.** You want an agent you can read and change.
- **Windows.** Amp runs on Windows only through WSL.
- **A second opinion.** A different agent often solves the task Amp is stuck on.

## The Best Alternatives

### Claude Code

Anthropic's agent has the widest range of parallel modes: subagents, `/batch` runs across worktrees, an agent view for background sessions, cloud sessions, and Remote Control, plus plugins, skills, and hooks. It needs a paid Claude plan or an API key.

See [Claude Code vs Amp](/compare/claude-code-vs-amp) and [Superset vs Claude Code](/compare/superset-vs-claude-code).

### Codex CLI

OpenAI's agent is open source under Apache-2.0 and comes with ChatGPT plans. It has subagents, worktrees, `codex exec` for CI, an SDK, a GitHub Action, and cloud tasks.

See [Superset vs Codex](/compare/superset-vs-codex).

### OpenCode

OpenCode is the most popular open-source agent with free choice of provider. It has a terminal UI, a desktop app, an IDE extension, built-in subagents, and a server with an SDK. It is MIT-licensed and free; you pay only for the models.

See [Superset vs OpenCode](/compare/superset-vs-opencode).

### Droid

Factory's agent runs frontier and open-weight models, and in the CLI you can bring your own keys. Missions coordinate several agents on larger work, and Droid connects to Jira, Linear, Slack, and PagerDuty.

See [Superset vs Factory](/compare/superset-vs-factory).

### GitHub Copilot CLI

Copilot's terminal agent offers models from several vendors on one plan, starting with a free tier. Issues, pull requests, and the GitHub MCP server are built in, and `/delegate` hands work to Copilot's cloud agent.

See [Superset vs GitHub Copilot](/compare/superset-vs-github-copilot).

### Devin CLI

Cognition's local agent hands sessions off to cloud Devin when a task gets long, and runs in an OS-level sandbox. Choose it if Amp's orbs are the feature you use most.

See [Superset vs Devin](/compare/superset-vs-devin).

### Superset (to run them all)

Superset is not an agent. It is a desktop workspace that runs Amp and every agent above, each in its own Git worktree and terminal, on your own subscriptions and keys; Superset never proxies model calls. Give the same prompt to Amp and Claude Code in two workspaces, review both diffs in the Changes pane, preview the result in the in-app browser, and open a PR from the better one. Workspaces run on your machine, on hosts you add, or in cloud workspaces, and the [iPhone and iPad app](/mobile) reaches all of them.

- For several vendors' models on one low-cost plan, choose **Copilot CLI**.

## Frequently Asked Questions

### What is the best Amp alternative?

Claude Code is the strongest alternative for deep work, Codex CLI is the best open-source agent from a major lab, and OpenCode is the best open-source option for any model.

### Is there an open-source Amp alternative?

Yes. Codex CLI (Apache-2.0) and OpenCode (MIT) are open source. Amp is proprietary.

### Is there a free Amp alternative?

Yes. Copilot CLI and Devin CLI have free tiers, Codex includes limited use on ChatGPT Free, and OpenCode is free with your own model keys. Amp itself is free with your own compute and keys.

### Can I use Amp and Claude Code together?

Yes. Superset runs both side by side, each in its own worktree. You pay each provider for its own usage.
