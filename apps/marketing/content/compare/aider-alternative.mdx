Aider is an open-source AI pair programmer for the terminal. It maps your repository, edits files, and commits each change to Git, with models from Anthropic, OpenAI, Google, DeepSeek, or a local endpoint. It is Apache-2.0 and free. Its last tagged release, v0.86.0, shipped in August 2025, and agents have since added subagents, worktrees, and cloud runs. Superset lets you run Aider and any newer agent side by side, each in its own Git worktree, so you can compare the diffs on your own code.

**Our recommendation: try a newer agent next to Aider in Superset, and keep whichever does better on your tasks.** The list below covers open-source agents and the major labs' agents.

## Why Look for an Aider Alternative?

Aider is still a clean, fast loop for focused edits. Common reasons to look further:

- **Release pace.** The last tagged release was v0.86.0 in August 2025.
- **Agent features.** Newer agents run subagents, use worktrees, and hand long tasks to the cloud.
- **Parallel work.** Aider runs one interactive session per terminal and commits to the current branch.
- **Tools.** Every major agent now supports MCP servers.

## The Best Alternatives

### OpenCode

OpenCode is the closest match to Aider's model freedom: an MIT-licensed agent that works with any provider, with a terminal UI, a desktop app, an IDE extension, built-in subagents, and a server with an SDK. It is free; you pay only for the models.

See [Superset vs OpenCode](/compare/superset-vs-opencode).

### Codex CLI

OpenAI's agent is open source under Apache-2.0 and comes with ChatGPT plans. It has subagents, worktrees, `codex exec` for CI, an SDK, a GitHub Action, and cloud tasks.

See [Superset vs Codex](/compare/superset-vs-codex).

### Claude Code

Anthropic's agent has the widest range of parallel modes: subagents, `/batch` runs across worktrees, cloud sessions, and Remote Control, plus plugins, skills, and hooks. It is proprietary and needs a paid Claude plan or an API key.

See [Superset vs Claude Code](/compare/superset-vs-claude-code).

### Pi

Pi is a minimal, MIT-licensed harness that works with any provider. It skips subagents and permissions on purpose, and you add what you need with extensions. Choose it if you liked how little Aider got in your way.

### GitHub Copilot CLI

Copilot's terminal agent offers models from several vendors on one plan, starting with a free tier, with issues, pull requests, and the GitHub MCP server built in.

See [Superset vs GitHub Copilot](/compare/superset-vs-github-copilot).

### Superset (to run them all)

Superset is not an agent. It is a desktop workspace that runs any CLI agent, each in its own Git worktree and terminal, on your own keys; Superset never proxies model calls. Aider runs as a custom agent command, and OpenCode, Codex, Claude Code, Pi, and Copilot CLI are built-in presets. Give the same prompt to Aider and a newer agent in two workspaces, review both diffs in the Changes pane, and open a PR from the better one. Because each workspace has its own branch, Aider's auto-commits stay on that branch.

See [Superset vs Aider](/compare/superset-vs-aider).

## How To Choose

- For open source with any model, choose **OpenCode**.

- For a minimal harness like Aider, choose **Pi**.
- For several vendors' models on one low-cost plan, choose **Copilot CLI**.
