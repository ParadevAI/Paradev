SUPER-3017 · mockup

An environment that says how fresh it is, and lets you rebuild it

Today an environment's page cannot tell you when its snapshot was built, from which commit, or whether the daily rebuild failed. Laid out like Cursor's environment page: an Overview card, then Builds with Trigger new build.

What is wrong today

Settings → Environments, and the environment page it links to.

Two detail screens for one environment.

A row opens a variables-only view (EnvironmentSecrets). The pencil opens another page (EnvironmentView) with the properties.

"Checkpoint saved" is never stale.

It reads environments.updatedAt. Every nightly release moves bundleSha, so a September snapshot says "3 hours ago".

Nothing says what builds the snapshot.

You cannot see whether the environment has an [install], so you cannot tell whether a rebuild can run.

The list hides health.

Rows show a name and repositories. A failing environment looks like a healthy one until a workspace boots slowly.
